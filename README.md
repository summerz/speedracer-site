# Speedracer

Three.js 기반의 브라우저 드론 레이싱 게임. 격납고에서 기체와 추진 효과를 확인하고, **주행 테스트**에서 순환 트랙을 직접 조종할 수 있다. P2까지 구현했으며 추적·콕핏·전체 트랙 시점을 전환하며 자유 주행할 수 있다.

```sh
npm ci
npm run dev
```

브라우저에서 <http://127.0.0.1:5273>을 연다. 주행 화면은 <http://127.0.0.1:5273/#drive>로 바로 진입할 수 있다.

조작: W/S 가감속, A/D 조향, ↓/↑ 한 번으로 인접 고도 하강·상승, Space 부스트(연속 3초 후 2단계), F 복귀, R 재시작, Esc 일시정지, C 추적·콕핏 전환, X 주행만 → 트랙 PIP → 트랙 메인·주행 PIP 순환. 시작 화면에서 초급·중급·고급을 선택한다. 트랙 폭·코너·스프링 회전 수와 장애물 배치가 달라지고 고도는 각각 2·3·4단계다. 기본 속도는 일반 306km/h, 부스트 450km/h, 2단계 558km/h이며 급한 코너에서는 S로 감속해야 한다. 모든 트랙에 큰 수직 루프와 오르내림, 반원 아치, 통과 시 감속하는 방전 장벽을 갖는다. 랩 판정과 결과·기록 저장은 P3에서 구현한다. 게임 규칙 검증은 `npm test`, 빌드는 `npm run build`로 실행한다.
