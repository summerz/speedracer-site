# Speedracer

Three.js 기반의 브라우저 드론 레이싱 게임. 격납고에서 기체와 추진 효과를 확인하고, **주행 테스트**에서 순환 트랙을 직접 조종할 수 있다. P2까지 구현했으며 추적·콕핏·전체 트랙 시점을 전환하며 자유 주행할 수 있다.

```sh
npm ci
npm run dev
```

브라우저에서 <http://127.0.0.1:5273>을 연다. 주행 화면은 <http://127.0.0.1:5273/#drive>로 바로 진입할 수 있다.

조작: 자동 가속, S 감속, A/D 조향, ↓/↑ 한 번으로 인접 고도 하강·상승, Space 부스트(연속 3초 후 2단계), F 복귀, R 재시작, Esc 일시정지, C 추적·콕핏 전환, X 주행만 → 트랙 PIP → 트랙 메인·주행 PIP 순환. 시작 화면에서 초급·중급·고급을 선택한다. 트랙 폭·코너·스프링 회전 수와 장애물 배치가 달라지고 고도는 각각 2·3·4단계다. 기본 속도는 일반 306km/h, 부스트 450km/h, 2단계 558km/h이며 급한 코너에서는 S로 감속해야 한다. 모든 트랙에 큰 수직 루프와 오르내림, 반원 아치, 통과 시 감속하는 방전 장벽을 갖는다. 3초 카운트다운 후 24개 체크포인트를 순서대로 통과해 3랩을 완주한다. 결과에서 총 시간·랩별 시간·최고 기록을 확인하고 재도전한다. 기록은 난이도와 성능 설정별로 브라우저에 저장한다. 게임 규칙 검증은 `npm test`, 빌드는 `npm run build`로 실행한다.

배포: <https://speedracer.summerz.net> · 저장소: <https://github.com/summerz/speedracer-site>. `main` 푸시 시 테스트와 빌드를 통과하면 GitHub Pages에 배포한다. v0.2.0부터 웹앱 설치·로딩 표시·수동 업데이트를 지원한다. 모바일은 자동 가속하며 왼쪽 원형 조이스틱으로 조향·대각선 감속, 오른쪽 ㅏ 모양 컨트롤로 고도·부스트를 조작한다. 지원 기기에서는 부스트 단계별 진동과 고도 변경 시 짧은 진동을 제공한다. [배포 안내](docs/DEPLOYMENT.md)를 참고한다.

고도는 부스트 바로 왼쪽의 세로 단계선으로 확인한다. 높은 단계가 위에 놓이며, 현재 고도는 굵은 청록색, 장애물 통과 고도는 주황색으로 표시한다. 장애물이 가까우면 필요한 ↑/↓ 조작을 안내한다. 고도·부스트·충돌 안내는 주행 시점을 따라가므로 X로 화면을 교환하면 주행 PIP 안에 표시된다. Bloom·음향·진동은 메뉴의 설정 팝업에서 조절한다. 정지 중 시점 미리보기를 열면 큰 메뉴를 접고 장면을 보여준다. 모바일 진행·멈춤 버튼은 PIP 상단에 붙인다. [설치·업데이트 안내](docs/WEB_APP.md)를 참고한다.

격납고는 Bloom과 자동 회전을 기본으로 켠다. 각각 버튼으로 끌 수 있다.
