마지막 갱신: 2026-10-04

현재 단계: P2 사용자 조정·모바일 터치와 부스트 진동 구현·기술 검증 완료

다음 작업: 배포본 사용자 검토 후 P3 타임어택 경기 규칙

범위와 설계는 [개발 계획](GAME_PLAN.md)을 기준으로 한다. P0부터 P4까지 완료하면 첫 타임어택 버전이며, P5와 P6은 후속 개발이다.

## 체크와 기록 방법

- 구현 항목은 실제 작업이 끝났을 때 체크한다.
- 검증 항목은 직접 실행하거나 관련 테스트가 통과했을 때 체크한다. 구현만으로 검증 완료를 표시하지 않는다.
- 단계 검증을 마치면 아래 검증 기록에 환경, 결과, 남은 문제를 적는다.
- 결정이 바뀌면 개발 계획과 이 체크리스트를 함께 갱신한다.
- 문제가 재발하면 해당 검증 항목을 다시 열고 다음 작업에 반영한다.
