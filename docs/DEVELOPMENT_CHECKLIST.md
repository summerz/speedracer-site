# 드론 레이싱 개발 체크리스트

마지막 갱신: 2026-10-05

현재 단계: P0–P5, P6-A~D 구현·자동 및 브라우저 검증 완료. v0.7.0에서 P7 캠페인 24개 트랙·도시 배경과 P8 키보드 메뉴·표준 게임패드 입력을 추가했고, v0.7.1에서 랜드마크·거리별 배경 최적화·화면별 코드 로딩을 구현했다. v0.8.0에서 AI 상대 아이템을 추가했다. P4는 v0.5.0 iPhone 홈 설치 앱 사용자 검토 승인. 2026-10-05 캠페인 제한시간·난이도와 iPhone 도시/PIP 끊김에 관한 질문에 사용자가 진행을 막는 문제가 없다고 확인했다. 초기 24개 트랙·캠페인·도시 구현과 사용자 검토를 완료하며, 아래 정량 성능 측정과 실제 기기 후속 검증은 별도로 남긴다. iPhone 주행 중 확대 재발의 실제 기기 확인은 사용자 요청으로 보류한다.

후속 검증: 트랙별 플레이 피드백에 따른 난이도·제한시간 조정과 실제 컨트롤러 검토. 실제 iPhone AI 레이스·아이템 조작 검토와 모바일 발열·프레임 시간 측정은 별도로 유지한다. 아래 확대 재현 항목은 지금 진행을 막지 않는다.

범위와 설계는 [개발 계획](GAME_PLAN.md), 상점 세부 수치는 [상점·포인트 기획](SHOP_PROGRESSION.md), 캠페인과 신규 트랙은 [트랙·캠페인 기획](TRACK_CAMPAIGN.md)을 기준으로 한다. 작업 완료 여부는 이 문서 한 곳에서 관리한다.

개발 순서: **P0–P4 첫 타임어택 → P6-A 포인트 → P6-B 상점·기체·강화 → P6-C 집중 아이템 → P5 AI 레이스 → P6-D AI 상대 아이템 → P7-A 트랙 기반 → P7-B 캠페인 → P7-C 도시 배경 → P7-D 24개 트랙 → P7-E 검증·지속 확장 → P8 키보드 메뉴·게임패드**. P5/P6 번호는 기존 기능 분류를 유지하며, 실제 작업은 이 순서로 이어간다.

## 체크와 기록 방법

- 구현 항목은 실제 작업이 끝났을 때 체크한다.
- 검증 항목은 직접 실행하거나 관련 테스트가 통과했을 때 체크한다. 구현만으로 검증 완료를 표시하지 않는다.
- 단계 검증을 마치면 아래 검증 기록에 환경, 결과, 남은 문제를 적는다.
- 결정이 바뀌면 개발 계획과 이 체크리스트를 함께 갱신한다.
- 문제가 재발하면 해당 검증 항목을 다시 열고 다음 작업에 반영한다.

P1 조정 기록: 고도 조작을 Q/E 탭 전환으로 변경하고 하단·상단 방전 장벽 6개를 배치했다. 장벽은 접지 기둥 사이의 전기 아크이며 접촉 시 큰 감속과 섬광을 준다. 기체를 가까이 당기고 가속·부스트 시야각 변화에도 크기를 유지한다. 최고 속도와 조향을 높였고 기체·장비별 설정을 실제 주행에 연결했다. 체크포인트는 반원 아치로, 첫 트랙은 수직 루프·스프링을 포함한 약 4,112m로 확장했다. 기체와 카메라는 노면 회전을 자동으로 따르며 좌우·고도 조작도 노면 기준이다. 현재 기본 초급은 2단계이며 난이도 선택으로 중급 3단계·고급 4단계를 사용한다. 설정으로 N단계 확장도 지원한다. 세부 수치는 [개발 계획](GAME_PLAN.md)에 기록했다.

부스트 조정 기록: 완충 5초·연속 3초 진입, 2단계 최고 96m/s. 진입 시 카메라 후퇴·시야각 충격과 유지 중 외곽 왜곡을 연결하고, 빗금은 부스트에서만 굵고 진하게 표시한다. 합성 부스트음과 음향 토글도 제공한다.

P2 조정 기록: 초급·중급·고급은 폭과 코너, 스프링 회전 수·간격, 장애물 배치와 고도 단계가 함께 달라진다. 기본 속도는 같고 기체·장비 성능과 분리한다. C와 시점 버튼으로 추적·콕핏·전체 트랙 뷰를 전환한다. 콕핏의 유리를 숨기고 계기판 밝기를 낮췄으며 노면 회전과 추가 흔들림을 따로 설정한다. 전체 뷰에는 픽셀 폭 경로선과 위치 표식을 더했다. 부스트 연출은 사용자 요청에 따라 현재 수준으로 정리하고 추가 개선은 보류한다.
