# 마린시티 트랙 형상 재설계

## 원인 확인과 기준선

기준선: main `d6061ab` (0.19.21). `createCatalogTrack → authorClosedTrack → createTrack` 경로는 네온·마린이 동일하다. 마린 레시피의 loop 9개·helix 13개·roll 18개는 실제 제어점과 도로 프레임에 반영된다. 데이터 누락이 아니라 **좁고 길게 늘어진 기술, 비슷한 전체 윤곽, 분기 0개**가 문제다.

스턴트 span은 원래 윤곽의 호 길이 비율이다. 코일은 이 길이를 전진하면서 작은 원을 그리므로, 회전 수만 많아도 반경이 작으면 길게 늘어진 도로처럼 읽힌다. loop는 전진 경로에 원운동을 더하는 방식이므로 반경/진입 길이 비율이 작으면 수직 원보다 언덕에 가까워진다. roll은 도로 단면만 돌리고 중심선은 움직이지 않는다.

| 기준선 기술 | 반경 | 원래 윤곽 구간 | 회전 | 실제 뒤집힌 제어점 비율 |
|---|---:|---:|---:|---:|
| REEF CIRCUIT 루프 | 58m | 316m | 1 | 16% |
| FOREST WEAVE 루프 | 65m | 332m | 1 | 18% |
| VICTORY LOOP 루프 (네온) | 117m | 300m | 1 | 37% |
| ABYSS FLOW 코일 | 24m | 631m | 1 | 49% |
| RIFT DESCENT 코일 | 30m | 905m | 2 | 51% |
| COIL FOUNDRY 코일 (네온) | 39m | 723m | 3 | 50% |
| HELIX HEIGHTS 코일 (네온) | 33m | 1,002m | 4 | 52% |

뒤집힌 비율은 `authorClosedTrack` 제어점의 `up.y < 0` 비율이다. 코일/롤의 반전은 정상이나 큰 중심선 이동과는 별개다. 새 루프는 반경 120–155m, 코일은 48–78m로 키우고 실제 생성 프레임에서 반전·높이·구간 길이를 검증한다. 네온 형상은 바꾸지 않는다.

## 시각 계약 / 구현 범위

- `TrackDefinition.layout` / `Track.sample`이 확정 형상을 제공한다. 수중 유리관 등은 Claude 담당.
- 분기는 기존 `TrackFork` / `BranchRoute.cue`, 점프는 기존 `TrackJump` / `RaceSnapshot.jump`를 그대로 사용한다.
- 마린 분기 이름은 레시피 `routeNames`로 지정한다. cue의 left/center/right/lower/upper와 hazards 의미는 유지한다.
- 배경, `createRace`, 결과·캠페인 UI, 버전 번호는 이 작업에서 수정하지 않는다.

## 완료 검증

 분기 기준은 [FORK_AUDIT.md](FORK_AUDIT.md)의 5기체×3난이도×부스트 유무×확정 후 홀드 0.2/1.5초 전수 검사, 접촉·도달 실패 0, 분리 후 첫 100m 최대 곡률 ≤0.012m⁻¹를 유지한다. 새 트랙을 기존 39경로 기준선과 함께 검사한다.

### 생성된 도로의 전후 비교

아래 길이는 분기 우회 길이를 제외한 기본 한 바퀴이며, 기술 길이·높이는 `Track.sample`을 2m 간격으로 측정했다. 위 기준선의 뒤집힌 **제어점** 비율과 이 표의 실제 도로 **거리** 비율은 표본 방식이 달라 직접 같은 수치로 비교하지 않는다. 루프 6곳은 높이 범위 248–315m, 뒤집힌 도로 28–32%를 갖는다. 마린 16트랙 전체가 6km 이하이며 늘어난 주행 거리에 맞춰 제한 시간도 늘렸다.

### 분기 안전성

| 범위 | 경로 | 주행 검사 | 접촉·코스 이탈·진입 실패 | 입구 100m 최대 곡률 |
|---|---:|---:|---:|---:|
| 기존 네온 + 새 마린 | 55 | 3,300회 | 0 | 0.011862 m⁻¹ |
| 새 마린만 | 16 | 960회 | 0 | 0.011095 m⁻¹ |

각 경로마다 5기체×3난이도×부스트 유무의 30조합을 검사하며, 확정 뒤 방향 입력을 0.2초 / 1.5초 유지하는 두 변형을 모두 통과했다. 마린 인접 경로 최소 중심 간격은 26.50m다. 공통 입구의 선택 경계, `junctionLength`, 확정 이후 중앙 복귀 보정은 바꾸지 않았다. CROWN CURRENT 가운데 차선 장애물은 기존의 곡률·경사 안전 조건을 만족하는 구간까지 배치를 옮긴다. 이미 안전한 네온 배치는 그대로다.

재현: `npm run audit:forks -- --all-craft --json` 및 `npm run audit:forks -- --all-craft --hold --json`.

### 기록 호환성

마린 트랙 16개 revision을 1→2로 올려 이전 형상의 기록·고스트와 새 주행을 구분한다. 기존 통과에 따른 캠페인 해금·지갑·구매는 변경하지 않는다. 네온 revision과 형상은 그대로다.
