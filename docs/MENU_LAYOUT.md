# 메뉴 화면 정보 구조 (캠페인 · 상점)

캠페인과 상점은 "고르고 → 비교하고 → 실행한다"는 같은 흐름을 갖는다. 화면마다 이 순서가 시선 순서와 일치하도록 배치하고, 숫자는 문장 대신 시각 단위(별·핍·막대·델타)로 보여준다.

## 화면 모드

| 모드 | 조건 | 원칙 |
|---|---|---|
| P · 세로 폰 | `(max-width: 760px) and (orientation: portrait)` | 한 열. 목록 → 상세 전환. 주 행동 버튼은 하단 고정. |
| L · 가로 폰 | `(max-height: 500px) and (orientation: landscape)` | 두 칸(목록 \| 상세)을 한 화면에. 헤더는 한 줄. 각 칸이 내부 스크롤, 주 행동 버튼은 상세 칸 하단 고정. 레이싱 직전 화면이므로 회전 없이 출전까지 끝낸다. |
| D · 데스크톱/태블릿 | 그 외 | 두 칸. 주 행동 버튼은 첫 화면에서 보인다. |

개발 환경에는 `사운드 관리` 탭과 플레이테스트 포인트(1,000,000 P)가 추가된다. 모든 모드는 탭 4개 + 7자리 잔액에서도 줄바꿈 없이 버티고, 운영(탭 3개 · 짧은 잔액)에서도 빈 공간이 어색하지 않아야 한다.

## 공통 헤더

- P: 1행 워드마크 + 도구(음악·버전·설치), 2행 탭(균등 분할 세그먼트) + 잔액. 탭이 넘치면 가로 스크롤(개발 환경 전용 상황).
- 운영 빌드에는 `이용 분석` 버튼이 더해진다. 폭 430px 이하 세로 화면에서 이 버튼이 보이면 워드마크는 아이콘만 남긴다.
- L: 워드마크(캡션 숨김) · 탭 · 잔액 · 도구를 한 줄(약 56px)에.
- 화면 높이 계산에 헤더 높이를 하드코딩하지 않는다. 화면 루트가 `grid-template-rows: auto … minmax(0,1fr)`로 남는 높이를 나눈다.

## 캠페인

### 목록

- 상단 진행 요약: `통과 n/32` + `★ 획득/최대` + 진행 막대. 모드 버튼 안의 `통과 n/32`는 짧게 유지한다.
- 규칙 안내는 박스 대신 모드 아래 한 줄 보조 문구.
- 지역 헤더: 지역색 이름 + `통과 n/m · ★ a/b` + 지역색 얇은 진행 막대. 설명은 한 줄.
- 코스 카드: `번호 | 이름 + 메타 | 별`.
  - 메타: 코스 강도 6칸 핍, `2단 고도`, 경쟁 모드면 `3위 이내`.
  - 도전 가능: 강조 테두리 + `도전` 칩. 통과: 별 + 기록(mono). 새 코스: `NEW`.
  - 잠김: 낮은 높이(약 48px), 별 숨김, 흐린 이름 + `잠김`. 진행 상태가 목록에서 바로 구분되어야 한다.
- 모든 코스가 잠긴 지역은 한 줄 요약(`잠김 · n코스` + 코스 이름 나열)으로 접는다. 단, 선택된 코스가 있는 지역은 펼친다.

### 상세 (위에서 아래 = 중요도 순)

1. 3D 미리보기 (L에서는 제목 옆 썸네일 크기).
2. 제목 블록: `지역 · 번호`, 코스 이름, 획득 별.
3. 스펙 타일: 강도(핍) · 랩 거리 · 고저차 · 고도 · 장애물 · 랩 수를 한 줄 타일로.
4. 목표 카드: 통과 조건 + 랩/순위별 조건 대비 기록 표. 난이도 설명(`중간 · 장애물 9개 · 기본 경고`)은 이 카드의 머리말로 합친다.
5. 별 등급 사다리: ★ / ★★ / ★★★ 세 줄에 각 기준. 이미 얻은 단계는 강조. 감점 규칙은 그 아래 각주 한 줄.
6. 갈림길 (있을 때만).
7. 코스 특징 · 랜드마크: 태그 칩.
8. 최단 완주 기록 한 줄.

하단 행동 영역: 접근 상태 한 줄 + `도전하기 · 난이도` 버튼. P에서는 `position: sticky`로 하단에 붙여 내용을 가리지 않는다. 잠긴 코스의 버튼은 강조색 없이 비활성 표면으로 보인다. 터치 기기에서는 키보드 안내(`Enter 선택 · Esc 이전으로`)를 숨긴다.

## 상점

- 첫 화면에서 보여야 하는 것: 선택 기체 · 가격/보유 상태 · 구매/장착 버튼.
- 기체 선택: P는 가로 스크롤 카드(색 막대 · 이름 · 가격/장착 상태), D·L은 세로 목록(행 높이 약 44px).
- 성능 비교: 수치 나열 대신 막대. 장착 기체는 흐린 막대, 선택 기체는 색 막대, 오른쪽에 값과 델타(유리 = 청록 `+`, 불리 = 주황 `−`). 유불리 방향은 `droneStats().fill`(높을수록 유리)로 판단한다. 같은 기체면 델타를 숨긴다. 부스트 · 제동력은 막대 없이 보조 수치 줄로.
- 주 행동 버튼은 기체 이름 바로 아래(D·L), P에서는 하단 고정 바.
- 강화 카드: `이름 · 단계 핍(●●○) | 현재 → 다음 값 | 비용 버튼`을 한 카드에 압축.
- 아이템: 상단에 장착 슬롯 시각화(`▣▢ 1/2`), 아이템 카드는 이름 · 보유 수량 배지 · 구매 버튼 · 장착 수량 세그먼트.
- L: 미리보기 40% | 콘텐츠 60%, 두 칸 모두 남는 높이를 채우고 콘텐츠 칸만 스크롤한다.

## 검증 뷰포트

390×844(P), 844×390(L), 1440×900(D)에서 개발 환경(탭 4개)과 운영 빌드(`npm run build && npm run preview`, 탭 3개)를 모두 확인한다.
