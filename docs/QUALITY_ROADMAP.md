# 품질 로드맵 — v0.19.4 이후

마지막 갱신: 2026-10-10

v0.19.4(새 앱 아이콘)까지의 상태에서 서비스 품질을 올리기 위한 작업 목록이다. 2026-10-10 사용자와 논의해 순서를 정했다. 항목을 끝낼 때마다 체크하고, 배포 버전을 괄호에 적는다. 세부 기획이 필요한 항목은 착수할 때 별도 문서를 만들고 여기서 링크한다.

진행 원칙:

- 한 단계를 한 번에 배포한다. 단계 안의 작은 항목은 브랜치 하나에 모아서 머지한다.
- 4단계(트랙·배경)는 끝이 없는 작업이므로 "요소 하나 + 트랙 하나" 단위로 쪼개서 진행한다.
- 부하를 늘리는 작업(4단계 장식·불빛)은 2단계에서 잡은 성능 기준선 안에서만 넣는다.

## 1단계 — 결과 화면과 씬 구성

결과 화면과 도착 장면은 같은 화면이라 한 묶음으로 진행한다. 인트로 시네마틱(5초 코스 훑기)과 피니시 슬로모션이 이미 있으므로 그 위에 얹는다.

결과 화면:

- [x] 결과 패널을 HUD 왼쪽 자리에서 떼어 화면 전체를 쓰는 배치로 바꾼다. 위쪽 큰 기록·순위·별, 가운데 세부 정보, 아래 버튼 줄. 배치 시안을 먼저 사용자에게 보여준다. (0.19.6)
- [x] 세부 정보 한 줄: 구간(체크포인트)별 고스트·최고 기록 대비 차이(초록/빨강), 충돌 횟수, 니어미스 수, 부스트 사용 횟수. (0.19.6)
- [x] 결과 뒤 배경은 피니시 카메라가 천천히 도는 장면을 유지한다. (0.19.6)

출발 장면:

- [x] 인트로 코스 훑기 뒤에 출발선 기체 소개 장면을 넣는다. 내 기체를 비춘 뒤, 경쟁 레이스면 상대 기체들을 차례로 비춘다. (0.19.6)
- [x] 건너뛰기(아무 키·탭)는 기존 인트로와 같이 동작한다. 동작 줄이기 설정에서는 정지 화면으로 대체한다. (0.19.6)

도착 장면:

- [x] 도착 순간을 2~3가지 구도로 다시 보여준다(결승선 옆, 뒤따르는 시점, 위에서). 리플레이 저장 없이 도착 직전 몇 초만 기록해 쓴다. (0.19.6)
- [ ] 경주 중간 장면 리플레이는 고스트 저장 방식을 재활용해 나중에 붙인다. 이 단계에서는 하지 않는다. (남김)
- [x] 경쟁 레이스에서 먼저 도착한 상대 기체가 사라지지 않게 한다. 속도를 줄이며 결승선 너머에 늘어서거나 한 바퀴 더 돈다. (0.19.6)

## 2단계 — 성능 기준선과 자동 품질 단계

4단계에서 건물·불빛을 늘리기 전에 기준선을 잡는다.

- [x] 데스크톱·iPhone에서 트랙별 프레임 시간을 재는 간단한 측정 절차를 정리한다(개발 모드 표시 또는 콘솔 출력). (0.19.7, [측정 절차](AUTOMATIC_QUALITY.md). 기기별 기준선 값은 아직)
- [x] 기기 성능에 따라 블룸·그림자·장식 수를 자동으로 낮추는 품질 단계(높음·중간·낮음)를 둔다. 첫 몇 초 프레임을 재서 정하고, 설정에서 수동으로 고를 수 있게 한다. (0.19.7, 해상도·장식·빗방울 수 기준. 블룸·그림자 연동은 아직)
- [x] 모바일 점검: 충돌·니어미스 짧은 진동, 엄지 위치의 버튼 배치, 발열 시 품질 단계 하향. (0.19.7 진동·발열 하향, 0.19.8 엄지 호 배치)

## 3단계 — 튜토리얼

결과 화면과 씬이 정해진 뒤에 만든다. 화면이 바뀌면 안내도 바뀌어야 하기 때문이다.

안내 조건·화면 데이터 계약·연습 주행·집계는 [튜토리얼 흐름](TUTORIAL_FLOW.md)을 따른다.

사용자 결정: 별도 연습 세션에서 첫 코스의 고정 장애물을 단계 순서대로 사용한다. 안내 중에는 속도를 낮추고 필요한 조작 직전에 세계를 멈춘다. 니어미스는 자동 주행·최근접 정지 설명으로 익히며, 7단계 종료 후 일반 결과 대신 연습 완료 화면으로 첫 코스 시작/재연습을 선택한다. Codex는 이 흐름과 기록·보상 분리, Claude는 카드·대상 링·완료 화면을 연결한다.

- [x] 첫 실행 캠페인 첫 코스에서 조작 안내를 차례로 띄운다: 가속, 조향, 고도, 부스트, 브레이크, 안전 바닥·위험 표시, 니어미스. (0.19.9)
- [x] 일시정지 메뉴에 "연습 주행"을 넣어 안내를 다시 볼 수 있게 한다. (0.19.9)
- [ ] GA4의 "주행 시작 → 완주" 비율로 효과를 확인한다. (0.19.9 튜토리얼 이벤트 수집 시작, 배포 후 확인)

## 4단계 — 트랙·배경 정교화 (반복)

한 번에 다 하지 않고 요소 하나와 트랙 하나를 묶어서 진행한다. 새 요소마다 [트랙 카탈로그](TRACK_CATALOG.md)와 [위험 요소](HAZARDS.md) 문서를 갱신한다.

첫 묶음은 건물 불빛·광고판 움직임(Claude)과 VOLTAGE YARD 위쪽 경로의 하강 점프(Codex 로직 → Claude 표시)다. 거리·고도·판정·화면 데이터는 [점프 계약](TRACK_JUMPS.md)에 기록한다. 로직 브랜치 `feat/track-jump`와 시각 브랜치를 연결·검증한 뒤 사용자 요청으로 머지하며, 그때 체크한다.

트랙 요소:

- [x] 끊어진 트랙 점프: 위에서 뛰어 아래 구간으로 내려간다. 고도 조절 물리를 그대로 쓴다. 기존 트랙 하나를 재구성해 먼저 넣는다. (0.19.10 VOLTAGE YARD 위쪽 송전 우회로, 격납고 "기능 테스트"로 바로 진입)
- [ ] 분기 다양화: [갈림길 카탈로그](TRACK_BRANCHES.md)의 구조를 넓힌다(3갈래, 높이가 다른 분기, 위험 요소가 다른 분기). 첫 대상·규칙·시각 계약은 [ARENA RING 계약](BRANCH_VARIETY.md)에 정리한다. 두 번째 상하 선택·고정 위험 배치는 [TERRACE FLOW 계약](TERRACE_BRANCH.md)에 정리한다. (0.19.19 첫 트랙 09 ARENA RING 3갈래 공개, 0.19.20 전 분기 입구 감사·형상 개선과 입구 차선 표시, 0.19.21 02 TERRACE FLOW 높이가 다른 상하 분기)
- [ ] 기존 트랙 재구성: 새 요소가 들어간 트랙을 하나씩 늘린다. 마린 16트랙의 원인 확인·새 윤곽·대표 기술·7분기·선택형 점프와 전수 감사는 [마린 형상 재설계](MARINE_TRACK_REDESIGN.md)에 정리했다(시각 연결·머지 대기).

배경 장식(2단계 품질 단계 안에서):

- [x] 건물 불빛 깜빡임, 광고판 전환 같은 저비용 움직임. (0.19.10)
- [x] 빈 곳이 느껴지지 않게 거리별로 다양한 건물을 추가한다. (0.19.12)
- [x] 움직이는 요소: 서치라이트를 비추는 헬리콥터, 지나가는 비행체 등. (0.19.11)

새 구역:

- [ ] 도시가 아닌 구역 하나를 설계한다(미지의 행성, 수중 도시 등). 세계 배경을 통째로 만드는 일이라 가장 뒤에 둔다. 착수 시 [월드 환경](WORLD_ENVIRONMENTS.md)에 기획을 추가한다. 수중 도시 시험 주행의 데이터·환경 선택·진입은 [런타임 계약](ABYSS_RUNTIME.md)을 따른다. 마린시티 정식 4구역·16트랙(33–48), 네온 32번 어느 모드/난이도 통과 시 도시 해금은 [도시 구조 계약](CITY_STRUCTURE.md)에 구현했다(통합 브랜치 583/583 테스트 통과). Codex 데이터·진행과 Claude 도시 헤더·구역별 시각 연결을 검증한 뒤 머지 시 체크한다.
  - 사용자 선택: 수중 도시. 기획·분담은 [심해 도시 ABYSS](ABYSS_DISTRICT.md). 시험 트랙 1개를 기능 테스트로 먼저 공개한 뒤 캠페인에 편입한다. (0.19.13 TRENCH LINE 기능 테스트 공개, 0.19.14 구역 위 도시 단위: 네온시티·마린시티, 마린시티 4구역 색 미리보기. 도시 단위 데이터·캠페인 편입 남음)

## 5단계 — 주행 요소와 아이템

- [ ] 드리프트: 브레이크를 누른 채 코너를 돌면 미끄러지며 부스트 게이지를 채운다. 니어미스·클린 콤보와 같은 보상 체계에 넣는다.
- [ ] 지원 미사일: 상점에서 구매·선택하면 나를 추월하는 상대에게 유도 미사일이 날아가 한동안 멈춘다. 착수 전에 정할 것: 멈춤 시간, 상대도 쓸 수 있는지, 경쟁 레이스 난이도 균형. 기체 각성(오버드라이브)은 "나를 강하게", 미사일은 "상대를 약하게"로 역할을 나눈다. 세부는 [상점·포인트 기획](SHOP_PROGRESSION.md)의 소모 아이템 절에 추가한다.
- [ ] 패링: 미사일이 들어간 뒤 그 대응 수단으로 설계한다. 무엇을 막는지 먼저 정한다.

## 6단계 — 기타

- [ ] 결과 공유 카드: 트랙 그림·기록·별·기체를 한 장의 이미지로 만들어 공유(모바일 공유 시트, PC 저장).
- [ ] 오늘의 도전: 날짜로 트랙·기체·난이도를 정해 매일 하나씩 준다. 기록은 기기 안에 저장한다. 로그인·클라우드 저장이 들어오면 순위표로 키운다.
- [ ] 기체 추가: 카탈로그에 항목을 더한다. 비용이 낮아 필요할 때 끼워 넣는다.
