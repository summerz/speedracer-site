# 멋짐 요소 기획

레이스가 "잘 달렸다"는 느낌을 화면과 손맛으로 돌려주는 요소를 모은다. 기준은 세 가지다.

1. 실력에 반응한다: 잘하면 더 멋있어진다. 운으로 터지는 연출은 넣지 않는다.
2. 조작을 방해하지 않는다: 주행 중 연출은 1초 안에 끝나고, 시야 중앙을 가리지 않는다. 긴 연출은 주행 전후에만 둔다.
3. 기존 요소를 재사용한다: 부스트 워프·속도선·블룸·추적/콕핏 카메라·기록 저장소 위에 얹는다.

## 이번에 구현 (v0.19.0)

### 1. 레이스 인트로 시네마틱

- 레이스 화면에 들어오면 출발 전 약 5초 동안 카메라가 코스 위를 훑는다. 하늘에서 내려다본 코스 전체 → 랜드마크 근처 통과 → 출발선의 내 기체 뒤로 내려앉는 순서다.
- 하단에 타이틀 카드: `구역 · 번호`, 트랙 이름, 난이도, 랩 수. 경쟁 레이스는 출전 기체 수.
- 아무 키·탭·패드 버튼으로 건너뛴다. 다시 도전(재시작)에는 나오지 않는다. 동작 줄이기 설정에서는 정지 화면 타이틀만 보여준다.

### 2. 니어미스와 클린 콤보

- 니어미스: 전기선·통로·아크 레일을 안전 범위 가장자리 가까이(여유 1.2m 이내)로 통과하면 `NEAR MISS` 표시, 기체 주변 불꽃, 부스트 게이지 +8%.
- 클린 콤보: 장애물을 부딪히지 않고 연속 통과한 수. `CLEAN ×n`을 화면 우측에 작게 띄우고 5·10·20에서 색이 한 단계씩 올라간다. 부딪히면 0으로 돌아가며 짧게 깨지는 효과.
- 별점·기록 규칙은 바꾸지 않는다. 손맛과 부스트 보상만 준다.

### 3. 레이스 이벤트 콜아웃

- 퍼펙트 스타트: 카운트다운이 끝나는 순간(±0.15초)에 부스트를 누르면 `PERFECT START`와 함께 짧은 발진 가속. 늦거나 이르면 일반 출발이다. 출발 직후 상대 기체에 밀리는 문제도 줄인다.
- 마지막 랩: 마지막 랩에 들어서면 `FINAL LAP` 배너와 음악 강조.
- 추월(경쟁 레이스): 순위가 오르면 `P3 → P2`, 내려가면 짧게 붉은 표시.

### 4. 피니시 시네마틱

- 결승선을 넘으면 0.8초 슬로모션과 함께 카메라가 기체 옆으로 돌아 나간다.
- 스플래시: 타임어택은 `FINISH`와 기록, 경쟁 레이스는 `1ST`/`2ND`… 순위. 최고 기록이면 금색 플래시와 `NEW BEST`.
- 이어서 기존 결과 화면이 열린다. 동작 줄이기 설정에서는 슬로모션과 카메라 이동 없이 스플래시만.

### 5. 고스트 (타임어택)

- 트랙·난이도별 내 최고 기록 주행을 저장하고, 다음 도전에서 반투명 청록 와이어 기체로 함께 달린다.
- HUD에 고스트와의 차이 `−0.31` (앞섬, 청록) / `+0.42` (뒤짐, 주황).
- 저장은 기기 안(브라우저 저장소)에만 한다. 저장 공간이 막혀 있으면 고스트 없이 정상 진행한다.
