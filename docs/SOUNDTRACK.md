# MIDI 사운드트랙

제공된 `incoming-resources/tron_style_racing_ost/`의 MIDI 5곡을 `public/music/`에 복사했다. MIDI 원본의 노트·템포·코드 진행은 변경하지 않는다. 약 210 KB의 MIDI를 Web Audio로 합성하므로 MP3를 내려받지 않는다. 악기 음색은 제공 MP3의 렌더링과 다르다.

## 편곡과 재생

베이스(채널 0), 빠른 고음 아르페지오(1), 낮은 음량의 지속 코드 패드(2), 드럼(9)을 재생한다. 주 멜로디(3)와 혼(4)은 사용자 의견에 따라 음소거한다. 리드 멜로디를 패드로 옮기지 않고 기존 코드 파트만 남겼다. 표현·음량·팬·밝기 MIDI 컨트롤을 반영한다.

격납고·상점에서는 Grid Theme → Neon Pursuit → Light Cycle Run → Afterglow Circuit → Horizon Line 순서로 재생한다. 메뉴 간 이동은 현재 곡을 유지한다. 카운트다운을 시작하면 Light Cycle Run의 강한 구간으로 진입하고 Light Cycle Run → Neon Pursuit → Grid Theme 순환을 사용한다. 일시정지는 음량을 낮추며 재개 때 곡을 다시 시작하지 않는다. 격납고로 돌아오면 현재 곡을 유지하고 다음 곡부터 메뉴 순서를 따른다.

조용한 처음 16마디와 마지막 페이드 구간을 생략한다. 레이스는 32마디부터 시작한다. 그 사이의 전개·브레이크 구간은 그대로 이어 연주한다. 다음 곡을 미리 불러오고 첫 노트를 현재 곡의 끝 박자에 예약한다. 별도 엔진·충돌·부스트 효과음은 음악과 독립적으로 동작한다.

브라우저 정책상 처음 터치·키 입력 후 소리가 시작된다. 음향 설정은 로컬에 저장한다. 화면을 벗어나면 오디오 컨텍스트를 멈추고 돌아올 때 이어간다.

## 구현과 검증

- `midi.ts`: SMF 0/1, 일정 템포 PPQ, 러닝 스테이터스, 겹치는 노트, 파트별 컨트롤 읽기.
- `synth.ts`: 베이스·플럭·패드·드럼 합성과 노트 수 제한. 리드·혼은 오디오 노드를 생성하지 않는다.
- `soundtrack.ts`: 화면 수명과 분리된 단일 플레이어, 선행 예약, 곡 연결, 음향 설정.

자동 테스트로 5곡·음소거·전환 박자·일시정지·음향 토글을 검증했다. 브라우저 OfflineAudioContext에서도 시작 100ms 이내 소리와 아르페지오 파트 출력을 확인했다. 최종 음색·파트 간 음량은 실제 청취로 조정한다.
