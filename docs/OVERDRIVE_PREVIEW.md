# 코어 각성 외형 미리보기

개발 서버에서 `/dev/overdrive.html`을 연다. 게임에서 사용하는 실제 Three.js 기체를 기본/각성 상태로 나란히 렌더링한다. 전체 비교, 기체별 확대, 정면/후면, 고정 상태, 점화와 해제 애니메이션을 제공한다. 모바일에서는 세로로 배치한다.

| 기체 | 외형 변화 |
| --- | --- |
| Vanguard | 엔진 바깥으로 이동하는 날개와 높아진 후방 핀 |
| Needle | 긴 가변 날개와 백색 코어 |
| Hammerhead | 전방 장갑과 네 갈래 핀 |
| Catamaran | 양쪽 선체의 에너지 레일과 외측 날개 |
| Halo | 기존 엔진 주변의 이중 에너지 링과 보조 날개 |

공통 효과는 밝아지는 코어, 길어진 배기, 기체 주변의 가는 전기 아크다. 도로와 경고 표시를 가리지 않도록 큰 불투명 후광은 사용하지 않는다. 움직임 줄이기 설정에서는 아크와 배기의 반복 움직임을 멈춘다.

Bloom은 격납고와 같은 강도·반경·임계값(0.85 / 0.32 / 0.9)으로 기본·각성 기체에 동일하게 적용한다. 각성 시 bloom 강도를 올리지 않는다. `Bloom 켜짐/꺼짐` 버튼으로 펼쳐진 실루엣을 발광 번짐 없이 확인할 수 있다. 조명과 카메라 배치는 비교 화면용이므로 격납고의 화면 전체와 동일하지는 않다.

`createOverdriveEffect`는 기체의 기본 형상을 유지한 채 부품을 덧붙인다. `setStrength(0…1)`과 `update(delta, reducedMotion)`으로 전개 정도를 제어하고, `dispose()`에서 추가 자원을 해제하고 원래 발광을 복원한다. 실제 레이스의 각성 상태와 연결돼 있으며, 비교용 미리보기 페이지는 생산 빌드의 진입점에 포함하지 않는다.

화면의 +5%는 **2단 부스트 최고속도 대비 목표값**이다. 비교 화면의 재생은 0.6초 점화 → 5초 각성 → 0.6초 해제로 구성했다.

실제 레이스에서는 공통 도로의 황금색 정육면체 **각성 코어**를 먹어 보관한다. 코어는 랩당 하나만 배치하며 최대 3개까지 보관한다. 보유 개수만큼 부스트 오른쪽에 큐브가 한 줄로 표시되고, **큐브 터치 / W 키**로 한 개를 사용하면 5초간 자동 조향·고도 전환으로 돌파한다. 코스 위의 코어와 획득·발동 알림에는 이름표 없이 아이콘만 사용한다. 각성 중에는 날개 아이콘과 남은 시간 막대를 표시하며, 모바일 터치 영역은 44px 이상을 유지한다. 자세한 설명은 설정의 조작 안내에 둔다. 부스트 링(+100%p)과 패드(+50%p)와는 별도 자원이다. 기체별 2단 부스트 최고속도의 105%까지 가속하고, 벽·길막·전기 지뢰·아크 레일·다른 기체와의 충돌에 따른 감속·페널티·부스트 손실을 무시한다. 부스트 잔량은 보관된다. 종료 시 현재 통로의 안전한 위치·고도로 맞추고 진행 방향에 정렬한 뒤 약 0.65초에 걸쳐 일반 속도로 돌아온다. 일시 중지 중에는 지속 시간이 멈추고, 재시작하면 코어 재고가 초기화된다.

부스트는 아이템과 자연 충전 모두 최대 150%까지 저장한다. 한 번 누른 채로 최대 100%를 사용할 수 있으며, 150%에서 시작하면 50%가 남는다. 버튼을 놓았다가 다시 누르면 남은 잔량을 사용할 수 있다.

검증: 다섯 기체의 렌더링, 데스크톱/모바일 배치, 재생 후 기본 상태 복귀, 재고정, 강도 0과 잘못된 입력, 기체 이동/회전 이후 유한 좌표, 자원 해제와 원래 재질 복원을 브라우저에서 확인한다. 기존 레이스 변경은 별도 커밋 `8d52259`로 보존했다.

전체 테스트 460개와 TypeScript 검사·프로덕션 빌드를 통과했다. 각성 테스트는 코어 획득·보관 한도·재시작, 지속 시간, 부스트 잔량 보존, 모든 충돌 보호와 종료 시 조작 복귀를 포함한다. 32개 코스와 다섯 기체 조합을 확인했고, 세 난이도와 무작위 장애물 배치에서도 코어가 랩당 하나인 것을 검증했다. 브라우저에서 데스크톱 W 키와 모바일 큐브 터치 발동, 세로·가로 화면 배치와 일시 중지를 확인했다. 부스트 테스트는 반복 자연 충전으로 150%가 모이고 각 사용 후 50%가 남는지 확인한다.
