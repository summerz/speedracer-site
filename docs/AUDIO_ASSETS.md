# 오디오 리소스

레이스의 충돌·이탈 효과음에는 짧은 MP3 파일을 사용한다. 엔진·바람·비·고도 경고·부스트 알림은 기존 Web Audio 합성을 유지한다. 음악은 제공 MP3를 로비/경주로 나누어 스트리밍 재생하며 [SOUNDTRACK.md](SOUNDTRACK.md)에 정리한다. 효과음 파일이 준비되지 않았거나 다운로드/디코딩이 실패하면 해당 충돌·이탈 소리를 기존 합성음으로 즉시 재생한다.

## 파일 및 출처

| 게임 파일 | 원본 | 출처 | 역할 | 재생 게인 |
| --- | --- | --- | --- | --- |
| `src/assets/audio/collision.mp3` | `Audio/impactPlate_heavy_000.ogg` | [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) | 약 0.5초의 금속 타격. 전기선 충돌 시 합성 전기 파열음을 추가한다. | 0.65 |
| `src/assets/audio/off-track.mp3` | `Audio/forceField_000.ogg` | [Kenney Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds) | 약 1초의 SF 방전. 하강 음정의 합성음을 추가한다. | 0.50 |

두 팩 모두 CC0이며 상업적 이용과 수정이 가능하다. 원본 라이선스는 `src/assets/audio/LICENSE-impact.txt`, `LICENSE-scifi.txt`에 보관한다. 전체 팩은 저장소에 넣지 않는다. 최종 MP3 두 개의 합계는 약 18.9KB다.

변환은 FFmpeg의 `libmp3lame`을 사용했다. 모노, 44.1kHz, 96kbps로 압축하고 메타데이터를 제거했다. 앞부분의 -50dB 이하 무음을 제거하고, 출력 피크를 0.9로 제한하며 끝부분을 페이드아웃했다. 충돌은 0.42초부터 0.07초, 이탈은 0.87초부터 0.08초 페이드를 적용했다. 이 페이드는 짧은 효과음의 끝을 다듬는 용도다.

## 준비와 재생

- `raceEffectFiles.ts`가 파일 URL과 재생 게인을 정의하고 `createRace.ts`가 오디오에 전달한다.
- 레이스 준비 화면에서 인코딩된 파일을 미리 받는다. 첫 사용자 입력으로 `AudioContext`를 활성화한 뒤 디코딩한다. 재시작·환경 변경에는 받은 바이트를 재사용하고, 새 컨텍스트에서 다시 디코딩한다.
- 충돌 순간 준비된 버퍼를 즉시 재생한다. 준비되지 않았으면 합성음을 사용한다. 비동기 로딩 완료 시 과거 이벤트를 재생하지 않는다.
- 파일 소리는 알림 버스로 보내고 엔진·비·음악을 잠시 낮춘다. 다른 충돌이 발생하면 이전 알림을 취소한다. 엔진 루프는 유지한다.
- 일시정지·효과음 끄기·레이스 해제 시 재생 소스를 중지한다. 해제 후 완료된 디코딩 결과는 보관하지 않는다. 실패한 다운로드/디코딩은 다음 활성화에서 재시도할 수 있다.

## 버전과 오프라인 캐시

앱 표시 버전과 리소스 버전은 역할을 구분한다. 표시 버전은 `package.json`에서 관리하고, 리소스는 내용 해시로 자동 관리한다.

1. MP3를 TypeScript에서 import하면 Vite가 내용 해시를 파일명에 붙인다. 파일을 바꾸면 배포 URL도 바뀐다.
2. 빌드 플러그인이 모든 배포 파일의 SHA-256과 전체 리소스 세트의 세대 해시를 서비스 워커에 넣는다. MP3도 사전 캐시에 포함된다.
3. 새 서비스 워커는 이전 캐시에서 같은 URL의 파일을 찾아 SHA-256을 확인한다. 같은 내용이면 재사용하고, 없거나 변경/손상되었으면 다운로드한다. 고정 URL의 공개 리소스도 바이트를 검사한다.
4. 모든 파일 검증을 마친 뒤 새 버전이 업데이트 대기 상태가 된다. 사용자가 업데이트를 적용할 때 활성화한다. 설치 실패 시 현재 캐시를 유지한다.
5. 한 번 앱 준비가 완료된 뒤에는 네트워크가 없어도 캐시에서 효과음을 준비한다. 아직 이전 버전을 실행하는 다른 탭에는 이전 해시 파일을 제공한다.

파일을 교체할 때 별도 수동 리소스 버전 번호는 필요 없다. `src/assets/audio/`의 파일과 카탈로그를 수정하고 빌드하면 URL·SHA-256·세대 해시가 함께 갱신된다. 새 효과음을 추가할 때는 출처/라이선스, 재생 게인, 합성 fallback, 정지/해제 동작을 함께 기록한다.
