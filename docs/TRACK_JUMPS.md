# 끊긴 도로 점프 — 로직·시각 계약

4단계 첫 트랙은 06 VOLTAGE YARD의 위쪽 `송전 우회로`(`voltage-yard-fork:1`)다. 아래쪽 경로는 그대로 통과할 수 있다. 점프는 매 랩 같은 곳에 고정하고, 해당 트랙의 기록 제작 버전만 6 → 7로 올린다. 앱 버전과 머지는 시각 연결 후 사용자 요청 때 처리한다.

마린시티 재설계에서는 48 SURFACE RUSH의 오른쪽 `라군 점프`(`surface-rush-fork:1`, 점프 ID `surface-rush-drop`)에도 같은 규칙을 적용한다. 왼쪽 `수면 아치`는 도로가 이어지는 선택지다. 이 트랙은 고도 4단계 중 최고 3단계에서 출발해 0단계로 착지한다. 마린 트랙 revision은 2이며 [마린 형상 재설계](MARINE_TRACK_REDESIGN.md)에 전수 감사와 기체별 점프 검증을 기록한다.

## 주행 규칙

- 도로 끝 100m 전부터 높은 고도(이 트랙의 1단계)를 안내한다. 실제 진입 고도가 최고 고도 − 0.6m 이상이면 출발 성공이다.
- 약 61m의 공중 경로에서 기존 고도 조작으로 낮은 고도(0단계)를 선택한다. 도로가 다시 시작하는 지점부터 실제 거리 50m의 착지 여유가 있다. 그 끝에서 최저 고도 + 0.75m 이하여야 한다.
- 출발·착지 때 기체 반폭 1.6m를 도로 안에 둔다. 선택한 고도 번호 대신 보간 중인 실제 고도·횡위치를 검사한다.
- 새 점프 키, 최소 속도, 부스트 요구는 없다. 브레이크로 속도를 낮춰도 통과한다.
- 실패는 점프·랩당 한 번만 기존 장애물 충돌·감점과 가벼운 속도 손실(기본 기체 약 20%)을 적용한다. 출발 실패 뒤 착지에서 다시 감점하지 않고, 체크포인트 복구로 같은 통과를 중복 집계하지 않는다. 실패해도 진행도를 되돌리지 않는다.
- 실패 알림은 `DrivingState.notice = 'jump-missed'`다. 전기선의 `height-collision`과 구분해 문구·소리·진동을 연결한다.
- 성공은 `jumpsPassed`와 기존 클린 연속·장애물 통과에, 실패는 `jumpsMissed`와 기존 충돌·감점에 집계한다. 각성 동안 판정을 보호하며, NPC와 각성 자동 주행은 진입/공중/착지 고도를 따라간다.
- 안내 시작부터 착지 여유 끝까지 무작위 장애물·부스트 아이템의 부피가 겹치지 않도록 배치 슬롯을 예약한다. 각성 코어는 원래부터 공통 도로에만 놓인다.

## 경로·단위

`approachStart`, `start`, `end`, `landingEnd`, `rejoinEnd`는 **한 랩의 공유 진행도**다. 렌더러는 `track.sample(d, frame, jump.routeId)`를 그대로 사용한다. `start..end`에서 노면·난간·차선을 생략하고, `end..landingEnd`를 착지 구간으로 표시한다. `landingEnd..rejoinEnd`는 낮아진 도로가 원래 경로로 부드럽게 복귀하는 구간이다.

기존 호버 물리를 유지하기 위해 도로가 없는 동안에도 가상의 비행 기준선을 사용한다. `sample`은 원래 경로보다 착지면을 세계 Y축으로 12m 낮추고 끝단의 위치·접선·노면이 연속인 완만한 경로를 반환한다. 별도 중력이나 점프 속도는 추가하지 않는다. 하강으로 달라진 실제 경로 길이를 다시 적분·매개화해서 실제 속도, 거리와 두 갈림길의 공통 진행도를 유지한다. `physicalDistance`와 `advanceTrackDistance`를 계속 사용한다. 표시 거리와 착지 여유는 **실제 m**다.

현재는 분기 경로당 점프 한 개만 지원하며 같은 경로에 여러 recipe를 넣으면 오류로 거부한다. 랩 경계와 공통 합류 구간에는 배치하지 않는다.

## 점프 연출 개선 (2026-10-11, 로컬)

06 VOLTAGE YARD와 48 SURFACE RUSH에서 시험한 상승·슬로우·네 카메라 연출을 사용자 확인 후 확정했다. 아래 전 구역 확대에서도 같은 연출을 사용한다.

`jumpPresentation.ts`는 공중 진행률에 따라 기체를 비행 기준선보다 최대 **6.5m** 더 들어 올린다. 도로 끝을 벗어난 뒤 거리 진행률 4%(기본 연출에서 실제 약 0.5초) 안에 빠르게 솟아올라 정점에 도달하고, 이후 착지까지 천천히 내려온다. 기수도 이륙 때 들고 하강 때 내려 준다. 위치 곡선은 이륙·정점·착지에서 변화율이 0이어서 갑자기 튀지 않는다. 추적 카메라는 상승량 일부만 따라가 화면에서도 기체 상승이 보인다. 착지에는 최대 0.32m의 짧은 눌림을 더한다. 동작 줄이기 설정에서는 기존 완만한 상승량 1m만 적용하고 기수 회전·착지 눌림을 끈다. 이 표현은 고도 선택·충돌·출발/착지 판정을 바꾸지 않는다.

공중에 들어서면 완전 정지 없이 즉시 매우 느린 이동을 시작한다. 카메라는 **실제 시간 약 4초에 한 바퀴를 일정한 각속도**로 돌며 약 2초에 기체 정면을 보여 준다. 이동 진행은 `0.2u + 0.8u²` 곡선(`u = 실제 경과 시간 / 회전 시간`)을 따라 초반에 크게 느려졌다가 점진적으로 빨라진다. 매 프레임 남은 실제 거리와 현재 속도로 공통 시간 배율을 계산해 부스트 진입·가속에도 회전과 착지를 맞춘다. 저속에서는 정상 시간보다 빠르게 이동시키지 않도록 회전 시간을 늘린다. 카메라가 추적 시점으로 돌아올 때 착지하며, 착지 후 0.28초 동안 정상 시간으로 복귀한다. 플레이어·NPC·경기 시계·이동 장애물·배경·날씨에 동일한 시뮬레이션 시간을 적용한다. 고도 버튼과 일시정지 입력은 즉시 받는다. 제동·정지는 실제로 동작하고 위치를 강제로 옮기지 않으며, 정지나 충돌로 착지가 지연되면 카메라는 회전을 마친 추적 시점을 유지한다. 재시작·복구 시 연출 상태도 초기화한다. 동작 줄이기 설정에서는 카메라 회전을 생략하고 0.12초 동안 40%로 낮춘다. 시간 흐름 변경으로 기존 기록과 비교 조건이 달라져 점프 트랙 revision도 1 증가한다(고도 분기 변경과 겹치면 한 번만 증가).

점프마다 다음 네 연출 중 하나를 선택한다. 네 종류를 무작위로 섞어 모두 보여준 뒤 다시 섞으며, 묶음 사이에도 같은 연출이 연달아 나오지 않는다. 한 점프 안에서는 선택을 유지하고 일시정지에도 바뀌지 않는다. 슬로우·상승·착지 판정과 전체 연출 시간(기본 4초)은 네 종류 모두 같다.

| 연출 | 카메라 흐름 |
| --- | --- |
| 회전(확정한 기존 연출) | 도로가 끊기는 순간부터 0.55초 동안 속도·가속도 변화가 매끄러운 곡선으로 추적 시점과 연결하며 일정한 각속도로 한 바퀴, 중간에 정면, 마지막 3%에서 추적 시점 |
| 버드아이 | 도로가 끊기는 순간부터 전체 시간의 30%에 걸쳐 높이 22m의 상공 시점으로 부드럽게 이동, 72%부터 추적 시점으로 복귀. 위치와 방향 모두 연속, 컷 없음 |
| 로우 앵글 | 도로가 끊기는 순간 기체 아래 3.5m에서 올려다보는 컷 → 전체 시간 89%에 추적 시점으로 컷(기본 착지 0.44초 전) |
| 측면 | 로우 앵글과 같은 컷 타이밍, 기체 옆 약 10m에서 바라보는 샷 |

동작 줄이기에서는 네 종류 모두 카메라 전환을 생략한다. 로컬 개발 빌드에서만 진입 해시에 `&jumpShot=orbit|bird|low|side`를 붙여 특정 연출을 확인할 수 있다. 지정하지 않으면 무작위 선택이다. 배포 빌드에서는 이 매개변수를 무시한다.

### 로컬 연속 테스트

개발 서버에서 `#drive?track=voltage-yard&mode=time-attack&challenge=easy&test=1`로 들어가면 **점프 연출 테스트** 메뉴가 나온다. **네 연출 연속 보기**는 회전 → 버드아이 → 로우 앵글 → 측면을 실제 점프 구간에서 순서대로 자동 주행한다. 매번 점프 진입 안내 구간(도로 끊김 100m 전)에서 시작해 달려오는 과정부터 보여주고, 착지 후 1.1초를 보여준 뒤 다음 연출로 넘어간다. 마지막 연출 뒤에는 일시정지한다. 개별 연출 버튼으로 원하는 것만 즉시 다시 볼 수 있으며, 정지·코스 처음부터 버튼도 제공한다. 아래 17개 트랙 모두 같은 기능 테스트 메뉴를 쓸 수 있다.

DEV 전용이며 기능 테스트의 기록·보상 미저장 규칙을 따른다. 실제 주행 모델·고도 변경·착지 판정·슬로우를 사용한다. 일반 레이스나 배포 빌드에는 메뉴가 없다. 동작 줄이기 설정을 켜면 카메라 연출을 생략하므로 비교 시 끈다.

`tests/jumpPresentation.test.mjs`는 두 트랙 × 5기체 × 30/60/120fps의 착지 성공, 항상 양수인 공중 시간 배율과 점진적 회복, 등속 카메라 회전·정면 도달·추적 시점 복귀, 저속/일반/부스트 진입 시 회전과 착지 시간 일치, 일시정지, 착지 후 시간 복귀, 경주 시계·상대·장애물의 동일 시간 적용, 랩 반복·초기화·동작 줄이기에 더해 버드아이 연속성·로우/측면 컷 타이밍·무작위 선택의 다양성/안정성·네 연출의 동일한 시간 흐름을 검사한다.

## 공개 API

`src/game/track/trackJump.ts`:

```ts
interface JumpRecipe {
  readonly id: string;
  readonly branchId: string;
  readonly routeIndex: 0 | 1 | 2;
}
interface TrackJump {
  readonly id: string;
  readonly routeId: string;
  readonly approachStart: number;
  readonly start: number;
  readonly end: number;
  readonly landingEnd: number;
  readonly rejoinEnd: number;
  readonly drop: number;
  readonly launchLevel: number;
  readonly landingLevel: number;
}
interface JumpCue {
  readonly jump: TrackJump;
  readonly phase: 'approach' | 'airborne' | 'landing';
  readonly distance: number; // 다음 경계까지의 실제 m
  readonly requiredLevel: number;
}
withTrackJumps(track: Track, recipes?: readonly JumpRecipe[]): Track;
upcomingTrackJump(track: Track, distance: number, routeId?: string | null): JumpCue | null;
jumpPlacementClear(track: Track, distance: number, routeId?: string | null, radius?: number): boolean;
```

`Track.jumps?: readonly TrackJump[]`, `TrackDefinition.jumps?: readonly JumpRecipe[]`. `createCatalogTrack`은 갈림길 → 점프 → 무작위 장애물 순서로 만든다. `RaceSnapshot.jump: JumpCue | null`은 현재 선택 경로의 점프만 노출한다. 안내 범위 밖에는 `null`; 진입은 높은 고도, 공중·착지는 낮은 고도다. `distance`는 각각 출발선/도로 재개점/착지 여유 끝까지의 거리다.

`src/game/driving/jumpPassage.ts`는 DOM 없는 판정 모듈이다:

```ts
interface JumpPose { distance: number; altitude: number; offset: number; routeId?: string | null }
createJumpTracker(track: Track): {
  reset(): void;
  update(from: JumpPose, to: JumpPose, protectedFlight?: boolean): ('landed' | 'missed')[];
};
```

## 작업 경계·검증

초기 구현은 Codex가 주행 판정, Claude가 도로 끊김·경고 끝단·민트 착지 패턴을 맡았다. 2026-10-11 인계 이후 Codex가 로직·시각 검증을 모두 맡는다.

자동 검증은 모든 기체 × 30/60/120fps × 일반/부스트/브레이크/저속/NPC/각성 주행, 실제 고도의 출발·착지 판정, 잘못된 경로 무시, 랩별 중복 방지·복구·리셋, 무작위 배치, 기존 갈림길의 거리·접합 연속성을 포함한다.

진입 안내 100m와 착지 여유 50m는 유지한다. 기존 노면 60m에 세계 Y축 하강 12m를 더하므로 실제 비행 경로는 기존 경사·노면 회전에 따라 약 56–71m다. 짧은 분기는 복귀 램프만 최소 60m까지 줄이며 입구·합류 양끝에 최소 10m를 남긴다. 점프 밖 조향 곡률은 원래 경로 정의를 유지해 입구나 꽈배기의 조작 특성이 바뀌지 않게 한다.
