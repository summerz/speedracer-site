# 트랙 제작과 캠페인

갱신: 2026-10-05. 현재 구현 사양이며, 완료 여부와 남은 작업은 [개발 체크리스트 P7·P8](DEVELOPMENT_CHECKLIST.md)에서 관리한다.

## 화면과 진행

격납고 → 캠페인 → 타임어택/AI 레이스 선택 → 구역별 트랙 카드 → 미리보기/통과 조건 → 경기 준비 → 주행 → 결과. 자유 타임어택/AI 레이스도 계속 제공한다.

캠페인은 격납고·상점과 같은 fluid 레이아웃과 공통 헤더를 사용한다. 데스크톱은 목록/상세를 나란히, 모바일은 위아래로 표시한다. 잠긴 코스도 미리보기는 가능하고 시작만 제한한다. 해금/완료 코스는 언제든 재도전할 수 있다. 전체 경로는 구역색, 루프·코일·노면 회전은 같은 구역색의 채도를 높이고 명도를 낮춘 진한 색으로 표시한다. 구역이 추가되어도 주색에서 자동 계산하며 범례도 같은 색을 사용한다. 경로의 형태가 단순해도 노면 회전과 큰 고저차가 주행 경험을 바꾼다.

준비·결과에서 나가거나 주행을 포기하면 캠페인으로 돌아간다. 방금 경기한 모드의 탭·코스·쉬움/중간/어려움 선택을 유지하고 해당 카드에 포커스를 둔다. 결과에서 다음 코스를 바로 시작한 경우에도 실제 직전 코스를 기준으로 돌아간다. 자유 주행에서 나가면 저장된 캠페인 선택을 사용한다.

카드는 **통과 / 도전 가능 / 잠김** 상태와 선택한 난이도의 최고 별점·기록을 표시한다. 다른 난이도에서 통과한 경우 이를 구분해 표시한다. 상세의 통과 조건은 별도 강조 영역으로 보여주며, 선택한 난이도의 가장 좋은 통과 결과를 총시간·각 랩·AI 순위·보조 사용 여부로 비교한다. 최고 별점이 우선이고 같은 별점에서는 빠른 총시간을 우선한다. 더 빠른 패배가 통과 기록을 덮어쓰지 않는다. 최단 완주 기록은 별도로 유지한다. 기존 저장은 검증 가능한 통과 기록만 복원하며, 기록이 남아 있지 않으면 이전 버전 통과 완료로 표시한다.

## 두 캠페인의 규칙

| 항목 | 타임어택 | AI 레이스 |
| --- | --- | --- |
| 경기 | 단독 3랩 | 플레이어 + AI 7대, 3랩 |
| 통과 | 모든 랩이 해당 코스 제한 이내 | 난이도 1–2: 4위, 3–4: 3위, 5–6: 2위 이내 |
| 실패 | 랩 제한 초과 즉시 실격 | 해당 코스의 통과 순위 초과 |
| 다음 코스 | 통과 후 이 모드에서 해금 | 통과 순위 이내 완주 후 이 모드에서 해금 |
| 보상 | 실격은 0 | 완주 보상은 순위와 별개 |

해금·기록은 두 모드에서 독립한다. 각 모드 첫 코스부터 시작하고 직전 코스 통과 시 다음 코스가 열린다. 랩의 남은 시간을 이월하지 않으며 제한과 같은 시각의 통과는 인정한다. 첫 통과 보너스는 모드/코스당 `100 + 난이도 × 25 P`로 한 번만 지급한다. 해금·완료·보상을 원자적으로 저장하고 동일 경기 재저장은 중복 지급하지 않는다. 기존 소유 기체·강화·포인트는 보존하며 자유 주행 기록을 캠페인 통과로 바꾸지 않는다.

AI 출전 선수는 실력 6·5에 가까운 선두권 선수와 트랙 난이도 근처의 선수, 낮은 실력 선수를 섞어 선택한다. 내부 이름·기체·색·성향은 고정이고 출전 명단은 준비 화면에 표시한다. 모바일과 데스크톱의 기존 실력 조정을 유지한다. 재시작은 같은 명단으로 진행한다. 구성과 조정 기준은 [AI 레이스](AI_RACE.md)를 따른다.

## 트랙별 참가 난이도와 별점 — v0.15.0

코스가 가진 강도 1–6과 참가자가 고르는 쉬움/중간/어려움은 별도다. 코스의 모양·길이·고도 단계는 유지하고 제한시간, 장애물 수, AI 실력, 경고 거리를 조절한다. 준비·일시정지·결과에는 큰 트랙명과 함께 선택한 난이도를 표시한다.

| 참가 난이도 | 랩 제한 | 장애물 | AI | 고도 경고 |
| --- | --- | --- | --- | --- |
| 쉬움 | 기본 ×1.15 | 매 5번째 제거, 약 80% | 선발 강도 -1, 목표 속도 ×0.90 | 약 1.9초 앞 |
| 중간 | 기본 | 기본 | 기본 | 약 1.5초 앞 |
| 어려움 | 기본 ×0.90 | 충분한 간격의 일부 구간에 추가 | 선발 강도 +1, 목표 속도 ×1.08 | 약 1.15초 앞 |

제한시간은 초 단위로 반올림한다. 추가 장애물은 간격 180m 이상인 매 세 번째 틈의 중간에 두며, 장애물 수는 상세에 실제 값으로 표시한다. 모든 난이도에서 통과 고도는 주행마다 다시 추첨한다. 모바일 AI 완화는 참가 난이도와 함께 적용한다.

타임어택은 모든 랩이 제한 이내면 ★, 모든 랩이 제한의 97% 이내면 ★★, 90% 이내면 ★★★다. 충돌·이탈 없는 완벽 주행을 요구하지 않는다. AI 레이스는 통과 커트라인 4위인 코스에서 4위 ★ / 3위 ★★ / 1–2위 ★★★, 커트라인 3위에서는 3위 ★ / 2위 ★★ / 1위 ★★★다. 향후 커트라인 2위 코스에서는 2위 ★, 2위이면서 모든 랩 97% 이내면 ★★, 1위 ★★★다. 실패·실격은 별 0개다.

별점·통과 결과·최단 기록은 모드/코스/참가 난이도별로 저장하며 최고 별점은 떨어지지 않는다. 어느 참가 난이도든 통과하면 다음 코스가 열리고, 첫 통과 보너스는 모드/코스당 한 번만 지급한다. 쉬움으로 진행한 뒤 같은 코스에서 중간·어려움 별점에 재도전할 수 있다. 예전 기록은 중간에 귀속하며 기존 해금·소유·포인트를 유지한다. 검증 가능한 예전 결과는 별점을 계산하고 기록 없이 해금만 남은 코스는 별 1개로 보존한다.

난이도 규칙과 별점 판정은 `src/game/track/raceChallenge.ts`, 기록·이관은 `src/game/progression/campaign.ts`에서 관리한다.

## 트랙 구성 원칙

전체 형태와 특수 구간은 별도 제작 데이터다. 원·콩·엄지·8자·클로버·삼각·말굽·별·입체 매듭에 루프·코일·완전 회전을 조합한다. 모든 코스에 최소 1개 특수 구간이 있고 첫 코스부터 세 종류를 경험한다. 입체 교차는 상하 공간을 분리하며 닫힌 경로 접합·노면 좌표계 연속성을 검증한다.

길이는 약 2.6~5.5km이며 후반이라고 길어지지 않는다. 난이도도 현재 1~4/6 범위에서 오르내리고 새 구역 입구에서는 쉬어간다. 짧은 코스도 타이트한 시간·장애물·특수 구간으로 어렵게 만들 수 있다. 아래 제한시간은 기본 기체 5종 자동 주행을 통과한 초기 값으로, 실제 조종 후 조정한다. 자동 주행 결과는 모바일 사용자 난이도나 GPU 성능 측정이 아니다.

## 초기 24개 코스

기존 첫 코스 NEON CIRCUIT은 04로 옮겼다. 각 코스는 3랩이며 거리와 제한은 한 바퀴 기준이다.

트랙별 ID·구역·거리·난이도·고도 단계·랩 제한·특수 구간은 [트랙 카탈로그](TRACK_CATALOG.md)에 정리한다. 제작 데이터에서 표를 생성하므로 이 문서에는 같은 목록을 중복하지 않는다.

11은 반경 117m의 대형 수직 루프, 13은 높은 삼각 경로의 노면 360° 회전, 18은 두 곳의 360° 회전, 22는 급강하와 연속 720° 회전을 갖는다. 위에서 본 중심선만으로는 노면 회전을 알기 어려워 진한 구역색 구간과 상세 설명을 함께 제공한다.

## 도시 배경

6구역에 주거동·공장·관람석·타워·연구동·공중 플랫폼 실루엣을 배치한다. 월드는 어둡고 창문 층·옥상 발광이 보인다. 트랙 선은 선택 기체색, 배경은 구역색을 따른다. 창문마다 실제 광원을 만들지 않고 발광 재질로 표현한다.

고정 시드로 배경을 재현하며 건물·창문·상단 장식을 3개 InstancedMesh로 묶는다. 저품질에서는 창문을 줄이고 트랙 뷰/PIP의 전체 경로에서는 도시를 숨긴다. 배경에는 충돌 판정이 없고 주행 통로·특수 구간 주변을 비운다. 화면 전환 시 자원을 해제한다. v0.7.1부터 트랙 ID를 기준으로 이름·위치·규모가 고정되는 랜드마크를 배치한다. 계단형 주거 타워·연결교·전력 코어·원형 경기장·발광 돔·첨탑·궤도 링 7종이며, 선택 미리보기와 실제 주행에서 같은 구조물을 보여준다. 조각을 재질별 3개 메시로 병합하고 건물과 겹치지 않도록 한다.

거리별로 창문과 실루엣의 표시 범위를 나눈다. 저품질/균형/고품질에서 창문은 165/280/380m, 실루엣은 480/650/800m까지 표시한다(건물 경계 기준). 35m 이상 이동하거나 품질을 바꿀 때만 인스턴스 버퍼를 갱신한다. 랜드마크도 먼 거리에서는 숨긴다. 실제 기기 PIP/Bloom 프레임 시간·발열 측정은 남아 있다.

v0.10.0에서는 24개 코스 모두에 서로 다른 규모의 대형 랜드마크 3곳씩, 총 72곳을 배치한다. 구역마다 대표 형상·보조 형상·발광색을 지정하고, 트랙 전체와 구조물 간격·100m 이상 이어지는 전방 접근 시야를 검사한다. 일반 건물도 시야 통로를 비운다. 랜드마크 표시 범위는 저품질 1,400m, 균형/고품질 2,200m이며 구조물 경계를 기준으로 한다. 코스 선택 미리보기와 실제 주행은 같은 배치를 사용한다. [랜드마크 카탈로그](LANDMARK_CATALOG.md)에 7종 형상·6구역 조합·코스별 위치와 규모를 기록한다.

## 밤 시간대

모든 캠페인 코스에서 경기 화면 진입 시 한밤중·깊은 밤·동트기 직전·해가 진 직후 중 하나를 무작위 선택한다. 하늘·별·안개·주변 조명과 달·고리 행성·초승달·위성이 함께 바뀐다. 일시정지·재도전에서는 선택을 유지하며 경기 화면을 다시 열면 새로 고른다. 구역이 지정되지 않은 자유 주행은 한밤중을 사용한다.

천체는 하늘 셰이더 안에 지름 약 61–78°로 표현하며 아래쪽이 지평선에 잠긴다. 표면 명암·무늬·대기층과 고리를 합성해 거대한 먼 배경으로 보이게 한다. 카메라의 위치만 따라가고 방향은 월드에 고정하므로 루프·노면 회전 때는 하늘도 회전한 시야로 보인다. 전체 트랙 뷰/PIP에서는 하늘과 도시를 숨기고 주행 뷰에서는 유지한다. 추가 이미지·그림자·창문별 광원은 사용하지 않으며 물리·제한시간·저장 규칙·트랙 제작 버전은 유지한다. [월드 환경 카탈로그](WORLD_ENVIRONMENTS.md)에 시간대별 색·천체·선택 규칙과 코스 적용 범위를 기록한다.

## 저장과 확장

상세 카드의 같은 표에서 타임어택은 각 랩의 제한시간·통과 기록·여유/초과 초를, AI 레이스는 코스 난이도별 통과 순위 조건·통과 순위와 완주 랩 수를 비교한다. 해금에 사용한 통과 기록과 최단 완주 기록은 구분한다. 더 빠른 패배가 생겨도 통과 기록은 바뀌지 않는다. 이전 트랙 버전은 현재 조건과 비교한다는 안내를 붙이고 당시 기록이 없는 기존 저장은 숫자를 만들어 표시하지 않는다.

트랙 ID는 이름·배열 순서와 독립한다. 25번 이후 코스는 선행 ID를 지정해 카탈로그에 추가하며 기존 마지막 통과자가 즉시 도전할 수 있다. 이름/색/순서 변경은 통과 기록을 유지한다. 경로·규칙이 바뀌면 제작 버전을 올리고 최고 기록은 새 버전 슬롯에 저장하되 기존 기록/통과를 보존한다. 비노출/삭제된 코스의 저장도 지우지 않는다.

현재 카탈로그는 코드로 제작·검증하고 배포한다. 제한시간은 트랙 제작 데이터의 양수 값으로 명시하며 통과 판정 때문에 3D 경로를 생성하지 않는다. 격납고·상점·캠페인·주행 코드는 화면에 진입할 때 불러오고 선택 트랙의 경로/배경만 생성한다. 로딩 실패에는 재시도 버튼을 제공하고 화면 전환 중 도착한 이전 요청은 무시한다. 분리된 코드도 기존 웹앱 사전 캐시에 포함한다. 시각적 제작 도구는 후속 작업이다. 업데이트는 기존 웹앱 흐름을 사용한다.

## 키보드와 게임패드

준비·일시정지·결과를 포함한 메뉴에서 화살표로 버튼을 이동하고 Enter로 선택한다. 주행 중 ↑/↓는 기존 고도 조절이다. 표준 매핑 게임패드는 방향 패드/스틱 메뉴 이동, A 선택, B 뒤로를 사용한다. 주행은 왼쪽 스틱 조향, 방향 패드 ↑/↓ 고도, LT 감속, RT/RB 부스트, X 콕핏, Y 트랙 뷰, LB 사용 가능한 장착 아이템(집중 모드 → 시간 정지 → 전파 교란), Start 일시정지/계속이다. 버튼 이름은 Xbox 기준이며 다른 패드도 브라우저 표준 매핑의 대응 위치를 따른다. 게임패드의 브라우저 감지는 처음 버튼 입력 후 시작될 수 있다.

데스크톱에서는 목록·상세 패널의 위아래를 맞추고 각각 필요한 내용만 스크롤한다. 도전 버튼은 상세 하단에 고정한다. 너비 1,000px 미만 또는 높이 600px 미만에서는 목록과 상세를 별도 화면으로 표시하고 페이지 자체만 스크롤한다. 상세의 도전 버튼은 화면 하단에 고정하며 코스 목록 버튼 또는 Esc/B로 선택한 카드에 돌아간다.

캠페인 카드를 터치하거나 Enter로 선택하면 도전/다시 도전 버튼으로 포커스를 옮긴다. 데스크톱에서는 레이스 준비 화면의 시작 버튼에도 자동으로 포커스를 맞춰 Enter로 출발한다. 그 상태에서 Enter는 경기 준비로, Esc 또는 게임패드 B는 선택한 카드로 돌아간다. 잠긴 카드는 해금 안내에 포커스를 두고 Esc로 카드에 돌아간다. 카드에서 다시 Esc/B를 누르면 격납고로 이동한다. 열린 설정 팝업에서는 팝업을 먼저 닫고, 주행 중 Esc는 일시정지, 일시정지 중 Esc는 재개한다.

연결 해제·탭 숨김·포커스 상실은 입력을 풀고 메뉴의 부스트 유지가 출발로 넘어가지 않도록 한다. 음향 시작에 브라우저가 실제 키/터치 입력을 요구하는 경우가 있으므로 최초 음향 활성화는 기존 브라우저 정책을 따른다. 실제 패드 검증·재매핑·패드 진동은 체크리스트의 후속 항목이다.

## 검증과 남은 확인

24개 × 5종 기본 기체의 3랩 완주/제한/충돌/이탈, 경로 접합과 직교 프레임, 교차 여유, 저장/해금/실격 경계는 자동 검증한다. 데스크톱/터치 AI 각각 실제 경기 모델로 타임어택 24개를 통과해 얻은 포인트로 기체를 구매하고 AI 경주 24개를 진행하는 연결 검증도 한다. 매 경기 저장 재검증, 패배 시 해금 차단과 완주 보상, AI 전원 완주와 저장 순위 유지, 재도전 및 중복 보너스 방지를 포함한다. 자동 조종의 완주가 인간 난이도를 증명하는 것은 아니다.

화면 헤더·반응형·키보드·가상 패드는 브라우저에서 별도 검증한다. 2026-10-05 사용자가 현재 캠페인의 제한시간·난이도와 iPhone 도시/PIP 끊김에 관해 진행을 막는 문제가 없다고 확인했다. 초기 24개 트랙·캠페인·주변 도시 구현 및 사용자 검토는 완료한다. 전 코스 실기 수치 측정을 완료했다는 의미는 아니며, 실제 기기 발열·프레임 시간·메모리 측정, 실제 컨트롤러 확인과 보류한 iPhone 확대 재발 확인은 후속 항목으로 유지한다.

AI 통과 순위는 `campaignRankLimit`에서 결정하며 실제 해금 판정·목록·상세 비교·준비·결과 안내가 같은 기준을 사용한다. 1위 순위 보상은 유지한다. 기존 우승 기록과 해금은 유지하며, 새로 3·4위로 통과한 기록도 독립적인 통과 기록으로 저장한다. 기록이 없는 옛 저장은 당시 우승이 확인되는 기록만 복원한다. 2026-10-05 사용자 피드백에 따라 타임어택 1–8 코스의 데스크톱 난이도는 살짝 쉬운 수준으로 보고 제한시간을 유지한다.

캠페인 상단의 출전 기체 표시는 격납고에서 장착한 기체의 실제 모델 이미지·이름·유형을 보여주며, 주 발광색을 함께 적용한다. 누르면 격납고로 이동한다. 모바일 코스 상세에서도 표시를 유지하고, 다른 창에서 장착을 바꾸면 저장 갱신과 함께 표시를 갱신한다. 정적 이미지는 `public/craft-previews/`에 있으며 기존 Three.js 기체 모델을 같은 조명·시점으로 렌더링한 것이다. 새 기체를 추가하거나 외형을 변경하면 해당 `modelVariant` 이름의 이미지를 갱신한다.
