# 트랙 제작과 캠페인 기획

작성: 2026-10-05. 사용자 요청을 바탕으로 정한 다음 개발 방향이며, 캠페인과 신규 트랙은 아직 구현하지 않았다. 완료 여부는 [개발 체크리스트의 P7](DEVELOPMENT_CHECKLIST.md#p7-트랙-생성과-캠페인--신규-트랙-개발의-단일-작업-목록)에서만 관리한다.

## 화면 흐름

격납고에서 기체를 장착한 뒤 **캠페인 → 타임어택/경주 → 트랙 선택 → 경기 준비 → 주행 → 결과**로 진행한다. 기존 자유 타임어택과 AI 경기는 연습용으로 유지한다. 상점과 설정은 기존 진입을 유지한다.

캠페인 화면은 상단의 타임어택/경주 탭, 구역 선택, 트랙 카드와 선택한 트랙의 미리보기로 구성한다. 데스크톱은 트랙 목록과 미리보기를 나란히, 모바일은 목록에서 트랙을 누르면 상세 화면으로 들어간다. 주행 화면의 정보량은 늘리지 않는다.

트랙 카드에는 순서·이름·난이도 1~6·잠김/도전 가능/통과 상태를 표시한다. 선택한 트랙의 상세에서 3D 경로, 길이·랩 수·주요 특징과 통과 조건을 보여준다. 다음 도전할 트랙을 강조하고, 완료한 트랙도 언제든 선택할 수 있다. 잠긴 트랙도 이름과 미리보기, 해금 조건은 볼 수 있다.

결과에는 성공 시 다음 트랙, 항상 재도전·트랙 선택을 제공한다. 해금은 결과 저장 때 확정한다. 앱을 종료해도 진행 기록을 유지하고, 다음에 캠페인을 열면 마지막 선택과 다음 도전 위치를 복원한다.

## 두 캠페인의 규칙

같은 트랙 카탈로그를 사용하되 해금·통과 기록은 모드별로 독립한다. 각 모드의 첫 트랙은 처음부터 열려 있고, 직전 트랙을 통과하면 다음 트랙이 열린다. 한 모드를 먼저 끝내도 다른 모드의 도전은 남는다.

| 항목 | 타임어택 캠페인 | 경주 캠페인 |
| --- | --- | --- |
| 상대 | 단독 주행 | 플레이어 + AI 3대 |
| 통과 | 모든 랩이 해당 트랙의 최대 랩타임 이내 | 최종 순위 1위 |
| 실패 | 한 랩이라도 최대 랩타임 초과 | 2위 이하로 완주 |
| 다음 트랙 | 통과 시 이 모드의 다음 트랙 해금 | 우승 시 이 모드의 다음 트랙 해금 |
| 재도전 | 열린 트랙은 언제든 가능 | 열린 트랙은 언제든 가능 |

타임어택의 제한은 **한 바퀴마다** 적용한다. 이전 랩의 남은 시간을 다음 랩에 이월하지 않는다. 현재 랩의 남은 시간을 기존 시간 표시 위치에서 보여주고, 종료가 가까울 때 색과 짧은 안내로 강조한다. 제한을 초과하면 즉시 실격 결과로 전환하며 강제 복귀는 하지 않는다. 제한과 정확히 같은 시간에 통과하면 인정하고, 물리 시뮬레이션의 랩 통과 시각으로 판단한다. 랩 수는 트랙 데이터로 지정한다.

경주는 마지막 랩의 결승 통과 시점에 플레이어의 최종 순위를 확정한다. 단순히 한때 1위였다는 이유로 해금하지 않는다. 동률은 기존 경기 판정 규칙을 따른다. AI 출전은 트랙의 실력 범위·성향에서 선택하며, 각 선수의 이름·기체·발광색·특성은 고정한다. 같은 경기 재도전은 같은 상대를 유지한다.

실격은 완주 포인트와 해금이 없다. 경주의 2위 이하 완주와 통과한 트랙의 반복 완주는 기존 보상·이탈 감점 정책을 따른다. 최초 통과 보너스는 모드/트랙당 한 번만 지급하고, 완료 처리·해금·보상을 한 번의 저장으로 반영한다. 같은 결과를 다시 열어도 중복 지급하지 않는다. 보너스 액수는 첫 구매까지의 소요 경기를 확인한 후 확정한다.

기존 기체·강화·포인트와 자유 주행 기록은 보존한다. 과거 자유 주행 기록을 캠페인 통과로 자동 변환하지 않는다. 캠페인 타임어택은 AI 상대 아이템을 막으며, 집중 아이템 등 보조 사용 여부를 기록에 구분한다. 기존 공식 시계의 정책을 유지해 시간 완화 아이템으로 제한 시간을 늘리지 않는다.

## 트랙 데이터와 배포 확장

각 트랙은 고정 `id`, 표시 이름, 제작 버전, 구역, 표시 순서, 모드별 선행 트랙 ID, 경로 제작 데이터/시드, 폭, 고도 단계, 장애물, 배경 배치, 랩 수, 난이도, 최대 랩타임, AI 출전 조건을 가진다. 생성은 제작 과정에서 수행하고 검토한 결과를 배포한다. 매 경기 무작위로 길이나 난이도를 바꾸지 않는다.

진행 저장은 배열의 몇 번째 트랙인지가 아니라 `트랙 ID + 모드`를 기준으로 한다. 최고 기록은 트랙 제작 버전·주행 규칙·기체 성능·보조 사용 조건도 구분한다. 이름·배경·표시 순서를 변경해도 통과는 유지한다. 경로/규칙이 바뀌면 새로운 기록 버전에 기록하며 이전 기록과 이미 얻은 해금은 남긴다.

초기 24개 이후에는 카탈로그 끝에 새 구역/트랙을 추가한다. 새 첫 트랙의 선행 조건을 기존 마지막 트랙으로 연결하면 이미 완주한 이용자는 업데이트 후 바로 도전할 수 있다. 트랙을 목록에서 숨겨도 저장 내용을 삭제하지 않는다. 해금 조건의 끊어진 참조·순환 의존·중복 ID는 배포 전 검사한다.

기존 웹앱 업데이트 흐름으로 새 카탈로그를 반영하고 새 트랙에 표시를 붙인다. 기존 진행 데이터에 없는 신규 ID는 미통과로 읽되, 선행 조건은 기존 기록으로 판정한다. 선택한 트랙과 필요한 건물 세트만 로딩한다. 초기 구동 시 모든 트랙의 3D 월드를 만들어 두지 않는다.

## 제작과 난이도 평가

현재의 트랙 중심 조종을 유지하면서 직선·커브·오르내림·수직 루프·스프링·노면 회전 구간을 조합한다. 구간 접합에서 위치·접선·노면 자세가 연속되어야 하고, 루프와 스프링에서도 카메라·고도·충돌 판정이 같은 기준을 사용해야 한다.

난이도는 폭, 곡률과 감속 필요 구간, 경사·회전, 장애물 간격과 고도 변경 여유, 연속으로 판단해야 하는 구간에서 후보를 산출한다. 이후 실제 플레이로 1~6단계를 확정한다. 루프가 크다는 이유만으로 자동으로 최고 난이도를 주지 않는다. 시각적으로 복잡한 구간과 조작이 어려운 구간을 구분한다.

초반은 넓은 트랙과 긴 회피 여유로 기본 기체도 통과할 수 있게 한다. 후반은 급커브·큰 오르내림·고도 전환을 결합하되, 속도감이 유지되는 긴 가속 구간도 넣는다. 구매나 특정 기체가 필수인 트랙은 별도 조건 없이 만들지 않는다.

최대 랩타임은 실제 트랙에서 기본/강화 기체와 모바일/데스크톱 기록을 모은 뒤 결정한다. 처음에는 공통 제한과 기존 모바일 조종 보조를 기준으로 검증한다. 플랫폼별 제한이 필요한 경우에는 적용 전에 선택 화면의 조건 표기와 기록 구분까지 함께 결정한다. 자동 AI의 완주 기록만으로 이용자의 제한 시간을 정하지 않는다.

## 트랙 주변 건물과 월드

월드는 어둡게 유지하고 먼 건물의 층층이 켜진 창문, 옥상·외벽의 선, 경기장의 링 조명을 보여준다. 트랙마다 배경 실루엣과 한두 개의 큰 랜드마크를 바꿔 다른 장소라는 느낌을 준다. 트랙의 주 발광선은 선택 기체 색을 따르고 도시 배경은 구역의 색조를 유지한다. 위험·출발·통과의 의미 색은 별도로 유지한다.

| 구역 | 건물과 장식 |
| --- | --- |
| 주거 | 높이가 다른 아파트, 반복되는 창문 격자, 옥상 안테나 |
| 산업 | 낮고 넓은 공장, 냉각탑·배관·변전 시설 |
| 경기장 | 원형/타원형 경기장, 계단형 관람석, 링 조명 |
| 고층 | 가늘고 높은 타워, 층별 수평 빛 띠, 건물 사이 연결교 |
| 연구 | 돔·다면체 연구동, 발광 패널, 원형 설비 |
| 공중 | 떠 있는 플랫폼, 궤도 링, 먼 대형 구조물 |

처음에는 단순한 3D 형상·발광 재질·라인과 창문 패턴으로 제작한다. 창문마다 실제 조명을 만들지 않고, 불이 켜진 층과 꺼진 층의 패턴을 고정 시드로 정한다. 같은 형상과 재질은 Instancing 등으로 묶고 먼 건물은 단순화하거나 실루엣으로 대체한다. 트랙을 바꿀 때 geometry·material·texture를 해제한다.

건물은 첫 버전에서 배경 장식이다. 주행 통로와 장애물 시야를 확보하고 루프/스프링 궤적 주변에도 여유 공간을 둔다. PIP에서는 경로와 선수 구분이 우선이므로 배경 디테일을 줄인다. 품질 단계별 건물 밀도·창문 디테일을 조절하고, 실제 iPhone의 Bloom/PIP 포함 프레임 시간과 메모리를 측정한다.

## 제작 순서와 완료 기준

P6-D 상대 아이템 이후 **카탈로그와 트랙 2개로 기반 검증 → 두 캠페인과 저장 → 도시 건물 세트 → 총 8/16/24개 제작 → 확장·실기 검증** 순서로 진행한다. 각 단계의 구현·검증 체크는 체크리스트에 기록한다.

24개 트랙은 경로 접합·충돌·고도·카메라·AI 완주를 자동 검증하고 실제 모바일/데스크톱으로 조종 난이도와 시간 제한을 별도로 확인한다. 캠페인은 모드별 해금, 실격/우승의 경계 시각, 재도전, 최초 보너스 중복 방지, 업데이트 전 저장 복원, 신규 트랙 추가 후 해금을 검증한다. 기존 P4 사용자 승인을 신규 월드의 성능 검증으로 간주하지 않는다.
