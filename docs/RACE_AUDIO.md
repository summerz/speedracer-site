# 레이싱 소리와 알림

현재 v0.15.0 기준. 음악은 앱 소유의 MIDI 재생기로 이어지고 엔진·충돌·날씨·알림은 경기 소유의 효과음으로 재생한다.

## 알림 구분

| 상황 | 소리 | 재생 조건 |
| --- | --- | --- |
| 부스트 충전 완료 | 고음의 금속성 벨, 3개 배음 | 게이지가 완전히 충전되는 순간 한 번 |
| 부스트 완전 사용 | 중음의 짧은 3음 상승 후 화음 | 완충 상태에서 끊지 않고 전부 사용했을 때 한 번 |
| 고도를 올려야 함 | 높은 휘슬 2회, 주파수 상승 | 가까운 장애물의 통과 범위보다 아래에 있을 때 |
| 고도를 내려야 함 | 부드러운 사인파 2회, 440→330→220Hz 하강 | 가까운 장애물의 통과 범위보다 위에 있을 때 |
| 장애물 충돌 | 저음 충격·거친 잡음·짧은 전기 파열 4회 | 전기선 충돌 시 |
| 코스 이탈 | 넓은 마찰 잡음·520→85Hz 하강·저음 충격 | 새 이탈 판정마다 |
| 천둥 | 저음 잡음과 짧은 균열음 | 번개 후 0.8–2.4초 뒤 |

고도 경고는 중간에서 대략 1.5초 앞의 장애물부터 시작하며 범위는 85–240m다. 쉬움은 이 범위를 1.9/1.5배, 어려움은 1.15/1.5배로 조절한다. 고속에서 범위 상한에 도달해도 난이도별 경고 거리 차이를 유지한다. 현재 높이를 먼저 확인하고 선택한 목표 높이도 확인한다. 통과 가능한 높이를 맞추거나 정지·음소거하면 경고를 즉시 끈다. 잘못된 방향을 바꾸면 이전 경고 음성을 끊고 새 방향의 소리를 낸다. 경고 반복 간격은 0.8초다.

충돌·이탈로 배터리가 감소한 경우에는 해당 부스트 사용의 성공 알림을 취소한다. 조작에 따른 작은 부하 소모는 정상 부스트 사용으로 인정한다.

## 겹침 처리

완주·마지막 랩 → 출발·카운트다운 → 랩·반 랩·고도 경고 → 부스트 알림 순으로 우선한다. 높은 우선순위는 재생 중인 낮은 알림을 끊고, 나머지는 순서대로 재생한다. 고도 경고 중 부스트 알림은 대기하며 2.5초보다 오래된 알림은 버린다. 충돌·이탈음은 알림을 끊고 0.32초 동안 새 알림을 막는다. 효과음을 알림 버스로 보내 배경에 묻히지 않게 하며, 배경 음량은 0.42초 동안 낮춘다. 지속 엔진과 음악의 재생 위치는 유지한다.

알림 중 음악은 기본 음량의 32%, 엔진·부스트·기계음·천둥은 28%로 낮아진다. 알림 음량은 그대로 유지한다. 음악과 지속 엔진을 다시 시작하지 않고 Gain 버스만 조절하며, 정지·초기화·음소거·경기 종료 시 원래 음량으로 되돌린다. 음악과 효과음의 개별 음소거 설정은 유지한다.

## 구현과 검증

- 상태 판정: `src/game/driving/createRaceSoundFeedback.ts`
- 음색·우선순위·효과음 버스: `src/game/driving/createRaceAudio.ts`
- 음악 버스: `src/game/audio/soundtrack.ts`
- 검증: `tests/raceSoundFeedback.test.mjs`, `tests/raceAudio.test.mjs`, `tests/midi.test.mjs`

자동 검증은 중복·방향·알림 겹침·배터리 사고 소모·음량 복구·음소거를 다룬다. 실제 음악과 소리가 함께 들리는 체감은 기기 스피커와 이어폰으로 추가 조정한다.
