# 새 구역 기획 — 심해 도시 ABYSS

품질 로드맵 4단계 "새 구역"의 기획이다(2026-10-10, 사용자 선택: 수중 도시). 도시가 아닌 첫 구역이며, 세계 배경 전체(하늘·안개·지면·주변 구조물·날씨 대체 효과)를 새로 만든다. 주행 물리, 장애물 규칙, 기록 체계는 바꾸지 않는다.

## 분위기

깊은 바다 밑에 지은 돔 도시를 달린다. 위로는 수면의 물결 빛이 일렁이고, 아래로는 모래 바닥 위에 물결 무늬 빛(커스틱)이 흔들린다. 시야는 지상보다 짧고, 먼 곳은 청록색 물빛 속으로 사라진다. 기존 구역의 네온 선과 3단 명암 톤은 그대로 유지하고, 색만 물속 쪽으로 옮긴다.

- 기준 색: 물빛 `#0a3a48`, 깊은 물 `#031219`, 발광 생물 시안 `#5ff5e6`, 산호 분홍 `#ff7aa8`, 경고 주황은 기존 값 유지.
- 구역 이름 후보: **심해 도시**(구역명), 트랙 이름은 기존처럼 영문 대문자 두 단어(예: `TRENCH LINE`, `CORAL GATE`).

## 도로

도로·난간·장애물 표시는 기존 그대로 쓰고 가장자리 색만 구역 색을 따른다. 일부 직선 구간 위에 유리 터널 아치를 씌워 "물속 관을 달리는" 느낌을 준다. 터널은 시각 장식이며 충돌·판정이 없다. 통로·전기선 같은 기존 장애물과 겹치는 구간에는 두지 않는다.
