# 장애물·부스트 카탈로그

장애물과 부스트의 단일 기준은 `src/game/track/hazardCatalog.ts`다. 레이아웃 코드는 거기서 `enabled`와 밀도·비율을 읽고, 이 표는 같은 내용을 사람이 읽기 위한 것이다. 항목 id가 코드와 이 표에서 어긋나면 `tests/hazardCatalog.test.mjs`가 실패한다. 용어 정의는 [glossary.md](glossary.md)를 따른다.

## 규칙

- **매 판 무작위**: 위치·순서·안전 고도·안전 통로·부스트 차선은 매 판 새로 굴린다. 아크 레일의 구간 선택, 첫 방향, 길이, 전환 횟수도 매 판 바뀐다.
- **트랙·난이도별 개수 고정**: 경로(주 도로와 갈림길 경로)마다 `round(실제 길이 / 간격)`으로 목표를 정하고, 종류별 개수는 판마다 바뀌지 않는다. 아크 레일은 간격 예산에 포함하지 않는다.
- **통과 가능 보장**: 지뢰밭은 안전한 선이 항상 있고(기울기 한계 이내), 어느 30m 구간이든 최소 두 차선이 막힌다. 아크 레일은 세그먼트 사이 빈 틈이 반대쪽 절반으로 건너갈 만큼 넓다. 부스트는 장애물 가장자리에서 40m 이상, 서로 120m 이상 떨어진다.
- **트랙당 부스트 한 종류**: 패드와 링은 같은 역할이라 트랙마다 한 종류만 쓴다. 트랙 id(자유 주행은 난이도 id)의 안정적인 해시로 정하며(`boostKindFor`), 약 절반씩이다. 개수 목표는 두 종류가 같다. 링 트랙은 루프·나선 중앙(활성 레일의 위험한 쪽 제외)과 일반 도로 모두에 링을 놓는다.

부스트는 기본 100%로 출발하고 자동 회복은 100%까지다. 아이템과 근접 통과 보너스는 최대 150%까지 예비 충전하며, 한 번 버튼을 누른 동안 최대 100%만 소비한다. 한도에 도달하면 남은 충전량을 보존하고 버튼을 놓았다가 다시 눌러야 한다.
