# 웹앱 설치와 업데이트

현재 버전은 **0.19.12**이다. 격납고와 주행 시작·일시정지 메뉴에서 버전을 확인한다.

## 설치와 시작

메뉴의 **앱 설치**를 누른다. 설치 프롬프트를 지원하는 브라우저에서는 해당 창을 열고, 그 외에는 안내를 제공한다. iPhone/iPad는 Safari 공유 메뉴의 **홈 화면에 추가**를 사용한다. Android/데스크톱에서는 브라우저의 앱 설치 또는 홈 화면 추가 메뉴도 사용할 수 있다.

HTML에 로딩 표시를 먼저 그려 초기 자바스크립트·게임 리소스를 기다리는 동안 상태를 보여준다. 로드 실패 시 다시 시도할 수 있다. 최초 온라인 실행에서 전체 앱 캐시 준비를 마치면 오프라인에서도 다시 열어 타임어택을 할 수 있다. 실제 설치·진동·발열은 사용자 기기에서 확인한다.

v0.5.1부터 문서 루트에 `touch-action: manipulation`을 적용해 iPhone Safari와 홈 설치 앱의 더블탭 확대를 막는다. 격납고·상점의 스크롤은 유지하고, 주행 캔버스와 조작부의 기존 `touch-action: none`은 유지한다. [WebKit의 터치 동작 설명](https://webkit.org/blog/5610/more-responsive-tapping-on-ios/)에 따라 하위 요소에도 더블탭 방지가 적용된다.

v0.6.0에서 경기 준비 화면의 타임어택 / 경쟁 레이스 선택, AI 3대와의 3랩 경쟁, 순위·접촉 감속·참가자별 완주 결과를 추가했다. 기록은 경기 방식별로 저장하며 기존 구매·포인트·설정은 유지한다. [경쟁 레이스 안내](COMPETITION_RACE.md)를 참고한다.

## 새 버전 적용

새 버전은 접속·복귀 및 주기적인 확인으로 준비한다. 주행 중에는 일시정지 버튼의 작은 점으로 알리고 자동으로 새로고침하지 않는다. 새 버전이 준비됐을 때만 메뉴에 **v… 업데이트 ↻** 버튼이 나타난다. 최신 버전 안내나 상시 업데이트 확인 버튼은 표시하지 않는다. 이 버튼을 누르면 주행을 멈추고 적용한 뒤 다시 시작한다. 진행 중인 경기는 초기화되며 저장한 최고 기록은 유지된다. 준비 실패 시 기존 버전을 유지하며 연결 후 다시 확인할 수 있다. 다른 탭은 자동으로 새로고침하지 않는다.

`../newrth`의 로딩·명시적 업데이트 흐름을 참고했다. 빌드에서 `package.json` 버전과 파일 SHA-256을 사용해 서비스 워커를 생성한다. 모든 파일 검증에 성공한 경우에만 후보 캐시를 준비하므로 일부 파일만 갱신된 배포를 적용하지 않는다. 이전 탭의 해시 자산은 캐시에 남겨 필요한 요청을 처리한다.

## 개발과 자산

```sh
npm version patch --no-git-tag
npm test
npm run build
npm run preview
```

개발 서버는 서비스 워커를 사용하지 않는다. 버전은 `package.json`에서 읽으며, 이 파일이 변경되면 Vite가 설정을 다시 읽고 화면을 자동 갱신한다. 장시간 켜 둔 서버에서 과거 버전이 표시되던 문제를 v0.3.2에서 수정했다. 배포 빌드의 미리보기에서 업데이트와 오프라인을 확인한다. 캐시를 초기화하려면 해당 사이트의 브라우저 저장 공간을 삭제한다.

아이콘 원본은 `design/app-icon.png`, 배포용 PNG는 `public/icons/`에 있다. 192·512px 기본 아이콘, 512px maskable 아이콘, 180px Apple 아이콘, 32px favicon을 제공한다. manifest는 `public/manifest.webmanifest`이며 사용자 도메인 루트에서 실행·설치한다.
