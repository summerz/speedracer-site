# Speedracer 용어집

프로젝트 문서, 게임 UI, 개발 대화에서 함께 사용할 용어를 정리한다. 아래의 **기준 용어**를 우선 사용하며, 영문은 코드와 개념을 연결하기 위한 참고다. 가격·보상·시간·성능 수치는 각 상세 문서와 현재 설정을 따른다.

## 캠페인과 트랙 구성

캠페인은 **구역 → 트랙**으로 구성한다. 이용자는 트랙에서 경기 방식과 참가 난이도를 선택해 레이스에 출전하고, 레이스 안에서 랩을 돈다. 타임어택과 경쟁 레이스의 캠페인 진행은 별도로 저장한다.

| 기준 용어 | 영문 | 의미 |
| --- | --- | --- |
| 캠페인 | Campaign | 트랙을 차례대로 통과하고 다음 트랙을 해금하는 진행 체계. 이미 열린 트랙은 다시 도전할 수 있다. |
| 구역 | District | 같은 도시 테마와 주색을 공유하는 트랙 묶음. 현재는 구역마다 트랙 4개가 있다. |
| 트랙 | Track | 이름과 고유 경로, 특수 구간, 장애물 구성, 통과 조건을 가진 주행 코스. |
| 레이스 | Race | 선택한 트랙에서 한 번 진행하는 경기. 같은 트랙에서도 경기 방식·난이도·기체를 바꿔 여러 레이스를 할 수 있다. |
| 경기 방식 | Race mode | 타임어택 또는 경쟁 레이스를 구분하는 선택. 참가 난이도와는 별개다. |
| 타임어택 | Time attack | 혼자 달리며 시간을 겨루는 경기 방식. 캠페인에서는 매 랩의 제한시간을 지켜야 통과한다. |
| 경쟁 레이스 | Competition race | 다른 기체들과 순위를 겨루는 경기 방식. 트랙별 통과 순위 이내에 들어야 캠페인을 통과한다. |
| 자유주행 | Free race | 캠페인 진행과 별도로 즐기는 경기. 캠페인의 다음 트랙 해금과 구분한다. |
| 랩 | Lap | 선택한 경로를 따라 트랙을 한 바퀴 도는 단위. |
| 반 랩 | Half lap | 한 바퀴의 절반에 해당하는 진행 단위. 중간 안내와 클린 보너스 판정에 사용한다. |
| 참가 난이도 | Challenge difficulty | 이용자가 고르는 **쉬움·중간·어려움**. 같은 트랙의 제한시간, 장애물, AI 실력 등 경기 조건을 조정한다. |
| 트랙 강도 | Track rating | 제작된 트랙 자체의 복잡도와 부담을 나타내는 등급. 카탈로그의 ‘트랙 강도 /6’에 해당하며, 참가 난이도와 구분한다. |
| 자유주행 난이도 | Free-race difficulty | 자유주행 설정의 **초급·중급·고급**. 캠페인의 쉬움·중간·어려움과 별도 설정이며 트랙 구성과 고도 단계 수에도 영향을 준다. |

현재 구역 구성은 다음과 같다. 트랙이 추가되면 번호 범위와 묶음 구성을 함께 갱신한다.

| 구역 | 현재 트랙 번호 |
| --- | --- |
| 네온 주거지 | 01–04 |
| 전력 산업구역 | 05–08 |
| 그랜드 아레나 | 09–12 |
| 미드나이트 스카이라인 | 13–16 |
| 프리즘 연구도시 | 17–20 |
| 오비탈 프런티어 | 21–24 |
| 네온 항만 | 25–28 |
| 솔라 사막기지 | 29–32 |

상세: [캠페인 규칙](TRACK_CAMPAIGN.md), [트랙 카탈로그](TRACK_CATALOG.md).

## 통과와 기록

| 기준 용어 | 영문 | 의미 |
| --- | --- | --- |
| 완주 | Finish | 경기에서 요구하는 모든 랩을 끝내는 것. 경쟁 레이스를 완주해도 순위 조건을 만족하지 못하면 캠페인 통과는 아니다. |
| 통과 | Clear | 해당 경기 방식의 통과 조건을 만족한 결과. 다음 트랙 해금과 별점 기록의 기준이다. |
| 통과 조건 | Clear requirement | 타임어택의 랩 제한시간 또는 경쟁 레이스의 통과 순위처럼, 캠페인을 통과하기 위한 기준. |
| 랩 제한시간 | Lap time limit | 타임어택에서 각 랩에 허용되는 최대 시간. 전체 경기의 제한시간과 구분한다. |
| 통과 순위 | Rank cutoff | 경쟁 레이스에서 통과로 인정하는 마지막 순위. ‘3위 이내’라면 1·2·3위가 통과한다. |
| 실격 | Disqualification | 제한시간 초과 등으로 해당 도전이 통과할 수 없는 상태가 되는 것. |
| 해금 | Unlock | 진행 조건을 만족해 잠긴 트랙이 도전 가능한 상태로 바뀌는 것. |
| 도전 가능 | Available | 출전할 수 있지만 아직 통과하지 않은 트랙 상태. |
| 잠김 | Locked | 트랙 정보를 살펴볼 수 있으나 아직 출전할 수 없는 상태. |
| 별점 | Stars | 통과 결과를 1–3개의 별로 평가하는 지표. 시간·순위와 충돌·이탈을 함께 반영하고, 경기 방식과 참가 난이도별로 기록한다. |
| 통과 기록 | Clear record | 통과 조건을 만족한 결과 중 보존하는 대표 기록. 더 높은 별점을 우선하고 같은 별점이면 더 빠른 기록을 우선한다. |
| 최단 기록 | Best time | 비교 가능한 조건에서 가장 빠르게 완주한 시간. 경쟁 레이스의 순위 조건을 만족하지 못한 기록도 통과 기록과 별도로 남을 수 있다. |
| 신기록 | New record | 기존 개인 최단 기록을 단축한 결과. 첫 기록 등록과 구분한다. |
| 보조 기록 | Assisted record | 아이템 보조 조건이 적용된 경기의 기록. 일반 기록과 분리해 비교한다. |

**별점은 결과 평가, 포인트는 상점 화폐**다. 높은 별점을 받은 기록과 가장 빠른 기록도 항상 같지는 않다.

## 트랙 형태와 장애물

| 기준 용어 | 영문 | 의미 |
| --- | --- | --- |
| 전체 형태 | Overall layout | 위에서 보거나 트랙뷰로 살펴본 경로의 큰 모양. 원형·8자·엄지형·매듭형 등이 있다. |
| 특수 구간 | Special section | 루프·코일·노면 회전처럼 일반 직선과 코너 이상의 입체 경험을 제공하는 구간. |
| 수직 루프 | Vertical loop | 주행 경로 자체가 수직 방향으로 원을 그리며 이어지는 구간. |
| 코일 | Coil | 주행 경로 자체가 스프링처럼 나선형으로 이어지는 구간. 대화에서 ‘꽈배기’ 또는 ‘스프링’이라고 부른 형태다. |
| 노면 회전 | Track roll | 진행 방향을 축으로 노면과 주행 기준 방향이 회전하는 구간. 경로 자체가 나선형인 코일과 구분한다. |
| 뱅크 | Bank | 코너 등에서 노면이 옆으로 기울어진 상태. 노면의 완전한 한 바퀴 회전과는 구분한다. |
| 입체 교차 | Grade-separated crossing | 경로들이 위아래 높이를 달리하며 교차하는 형태. 경로가 교차한다고 반드시 갈림길인 것은 아니다. |
| 갈림길 | Branch | 하나의 경로가 Y자 형태로 나뉘어 서로 다른 경험을 제공한 뒤 다시 합류하는 구간. |
| 좌우 갈림길 | Lateral branch | 좌측과 우측 경로 중 하나를 선택하는 갈림길. |
| 상하 갈림길 | Vertical branch | 위쪽과 아래쪽 경로 중 하나를 선택하는 갈림길. |
| 분기 / 합류 | Split / Merge | 갈림길이 시작되어 경로가 나뉘는 지점 / 나뉜 경로가 다시 하나로 만나는 지점. |
| 체크포인트 | Checkpoint | 경기 진행과 랩 판정을 확인하는 경로상의 기준점. 놓쳤을 때 뒤로 돌아가도록 요구하는 플레이 요소는 아니다. |
| 아치 게이트 | Arch gate | 트랙 위에 놓인 아크 형태의 시각 구조물. 장애물이나 체크포인트 판정 자체와 구분한다. |
| 출발 게이트 | Start gate | 출발 위치를 강조하는 별도 색상의 아치 묶음. |
| 전기선 | Electric barrier | 접지 구조 사이로 전기가 흐르며 특정 고도에서만 안전하게 통과할 수 있는 기본 장애물. 불투명한 벽 대신 앞이 보이는 형태다. 배치(위치·순서)와 안전 고도는 매 판 무작위이며, 트랙·참가 난이도별 종류별 개수는 고정이다. |
| 이동 전기선 | Moving electric barrier | 장애물 위치는 유지하면서 안전하게 통과할 수 있는 고도가 움직이는 전기선. 배치(위치·순서)와 움직임의 시작 위상은 매 판 무작위이며, 트랙·참가 난이도별 개수는 고정이다. |
| 좁은 주행 통로 | Narrow corridor | 기존 트랙 안에서 좌측·중앙·우측 중 안전한 통로를 표시해 그 안으로 주행하도록 유도하는 방해 요소. 배치(위치·순서)와 안전 통로는 매 판 무작위이며, 트랙·참가 난이도별 종류별 개수는 고정이다. |
| 전기 지뢰밭 (보류) | Electric minefield | 현재 보류: 트랙에 생성되지 않는다([HAZARDS.md](HAZARDS.md)). 도로 위 일정 구간에 세워진 전기 기둥(지뢰) 무리. 기둥은 모든 고도에서 닿으면 방전 접촉이며, 기체가 지나갈 수 있는 안전한 선이 매 판 새로 만들어진다. 진입 약 40m 전에 자홍색 경고 띠가 깔리고 250m(또는 3초) 앞에서 안내가 뜬다. 쉬움에서는 진입 차선도 알려 준다. 배치(위치·순서)와 안전한 선은 매 판 무작위이며, 트랙·참가 난이도별 개수는 고정이다. |
| 부스트 패드 | Boost pad | 도로 위 한 차선에 놓인 청록색 화살표 판. 패드 폭 안으로 지나가면(고도 무관, 한 랩에 패드당 한 번) 부스트 게이지가 35% 차오르고 속도가 즉시 붙는다. 일부는 좁은 주행 통로 80~120m 앞에서 그 통로의 안전한 길이 아닌 차선에 놓여 위험을 감수할 이유가 된다. 배치(위치)와 차선은 매 판 무작위이며, 트랙·참가 난이도별 개수는 고정이다. |
| 아크 레일 | Arc rail | 수직 루프·나선 구간에만 놓이는 라임색 전기 레일. 구간 안쪽 30m부터 끝 30m 전까지 이어지며, 한 번에 도로의 한쪽 절반(중앙선~가장자리)만 감전된다. 기체 폭의 일부라도 위험한 쪽 절반에 걸리면 어떤 고도에서든 좁은 주행 통로와 같은 감전 접촉이며, 구간(세그먼트)당 한 랩에 한 번만 적용된다. 구간은 80~150m이고 좌우가 번갈아 바뀌며 사이에 최소 80m(쉬움 120m)의 빈 틈이 있어 반대쪽으로 건너갈 수 있다. 200m(또는 3초) 앞과 전환 직전에 `⚡ 아크 레일 · 오른쪽 위험 ← 왼쪽으로` 안내가 뜬다. 첫 방향·구간 길이·전환 횟수는 매 판 무작위이며, 트랙당 레일 개수는 참가 난이도별로 고정이고(1·1·2개) 어느 구간에 놓일지는 매 판 무작위이다. |
| 부스트 링 | Boost ring | 청록색 고리. 수직 루프·나선 구간(구간당 최대 1개, 400m 넘으면 2개)과 일반 도로에 놓이며, 한 트랙은 패드와 링 중 한 종류만 쓴다. 고리 중심에서 반지름-0.8m 안으로 기체 중심이 지나면(고도 무관, 한 랩에 고리당 한 번) 부스트 게이지가 30% 차오르고 속도가 붙는다. 도로 한쪽으로 치우쳐 있고 활성 아크 레일의 위험한 쪽에는 놓이지 않으며 가능하면 레일 사이 빈 틈에 놓인다. 150m 앞에서 `⚡ 부스트 링 ← 왼쪽` 안내가 뜬다. 배치는 매 판 무작위이며, 코스별 개수는 고정이다. |
| 안전 고도 | Safe altitude | 해당 장애물을 충돌 없이 통과할 수 있는 고도. 현재 고도가 도달했는지와 함께 판정한다. |

상세: [트랙 카탈로그](TRACK_CATALOG.md), [갈림길 카탈로그](TRACK_BRANCHES.md), [개발 체크리스트](DEVELOPMENT_CHECKLIST.md).

## 기체와 주행

| 기준 용어 | 영문 | 의미 |
| --- | --- | --- |
| 기체 | Ship / Drone | 이용자 또는 AI가 탑승해 경주하는 드론. 현재 Vanguard·Catamaran·Halo·Needle·Hammerhead 5종이 있다. |
| 주 발광색 | Primary glow color | 기체 외형의 주요 네온선 색상. 기체 미리보기 받침과 트랙 장식의 색상 연동 기준으로 사용한다. |
| 가속도 | Acceleration | 속도가 목표 속도에 도달하는 빠르기. 최고 속도와 구분한다. |
| 최고 속도 | Top speed | 기체가 해당 주행 상태에서 낼 수 있는 상한 속도. 실제 속도는 경사·조향·충돌 등에도 영향을 받는다. |
| 좌우 핸들링 | Handling | 좌우 조작에 반응하고 방향을 바꾸는 성능. 속도와 경사에 따라 실제 반응이 달라진다. |
| 좌우 제동 | Lateral braking | 좌우 입력을 놓거나 반대로 바꿨을 때 옆으로 미끄러지는 움직임을 줄이는 성능. 전진 속도를 줄이는 브레이크와 구분한다. |
| 브레이크 | Braking | 전진 속도를 줄이는 성능. 감속 입력을 유지해도 기체는 느린 속도로 계속 전진한다. |
| 충돌 감속 | Collision slowdown | 충돌이나 이탈 직후 잃는 속도. 낮을수록 속도 손실이 적다. |
| 회복 가속 | Recovery acceleration | 충돌 뒤 정상 가속 성능으로 돌아오는 과정. 장애물 충돌과 기체 접촉은 회복 특성이 다르다. |
| 자동 가속 | Auto acceleration | 감속하지 않으면 기체가 자동으로 속도를 올리는 기본 조작 방식. |
| 고도 | Altitude | 트랙 노면을 기준으로 기체가 떠 있는 높이. 루프·노면 회전 중에도 세계의 수직 방향이 아니라 트랙 기준을 따른다. |
| 고도 단계 | Altitude level | 선택 가능한 이산적인 높이 위치. 트랙에 따라 단계 수가 달라지며 N단계로 확장할 수 있다. |

## 표기 원칙

- **구역**의 영문은 현재 코드의 `District`에 맞춘다. 이전 대화의 `Zone`도 같은 묶음을 가리키지만 새 문서에서는 `District`를 사용한다.
- **트랙**을 기준으로 쓰고 ‘코스’는 같은 뜻의 일상 표현으로 허용한다. **레이스**는 그 트랙에서 진행한 경기 한 번을 가리킨다.
- **코일**은 경로가 나선으로 도는 형태, **노면 회전**은 진행 축을 중심으로 노면이 도는 형태로 구분한다. ‘꽈배기’만으로 둘을 혼용하지 않는다.
- **쉬움·중간·어려움**은 참가 난이도, **트랙 강도**는 제작된 트랙의 등급으로 구분한다. **초급·중급·고급**은 자유주행 설정에 한정한다.
- **최단 기록**을 시간 기록의 기준 표현으로 쓴다. 기존 ‘최고 기록’ 표시는 시간 문맥에서는 같은 뜻이며, 별점과 통과 결과는 **통과 기록**으로 구분한다.
- **경로 이탈**을 기준 표현으로 쓰고 기존 ‘코스 이탈’은 같은 뜻으로 본다. 경계 접촉·장애물 충돌·기체 접촉과는 구분한다.
- **콕핏**, **추진기**, **전기선**으로 표기한다. ‘콧핏/콧픽’, ‘스러스터/쓰러스터’, ‘전기장/방전 장벽’ 등 기존 표현은 문맥에 맞춰 이 용어로 정리한다.
- 기능이나 개념이 추가되면 이 문서에 의미를 먼저 맞추고, 상세 동작과 밸런스는 해당 기획 문서에 기록한다. 기존 문서와 UI의 표기 통일은 관련 수정 시 함께 반영한다.
