# 상점과 포인트 기획

작성: 2026-10-04 · 갱신: 2026-10-11
상태: P6-A~C와 지원 미사일 로직 구현. 포인트 지급, 기체 구매·장착, 영구 강화, 집중 모드와 상대 대상 아이템을 연결했다. 지원 미사일의 시각 연출은 Claude가 연결한다. 가격·보상·조종 밸런스는 플레이 테스트 후 조정한다.

## 경기와 성장의 흐름

타임어택 또는 경쟁 레이스 3랩 완주 → 결과 화면에서 포인트 획득 → 격납고의 상점에서 구매 → 기체·강화·아이템을 장착 → 다음 경기 시작.

타임어택과 경쟁 레이스는 기본 완주 보상을 공유하고 최고 기록은 경기 방식별로 분리한다. 경쟁 레이스에는 최종 순위에 따른 추가 보상을 지급한다. 최초 기체는 무료이며 구매 없이 모든 난이도를 플레이할 수 있다.

통과 커트라인을 넘겨도 정상 완주하면 순위 보너스를 받는다. 중도 포기·실격에는 지급하지 않으며 타임어택에는 순위 보너스가 없다. 집중 모드에서도 순위 보너스는 유지한다. 이전에 저장된 보상과 잔액은 소급 변경하지 않는다.

첫 기록에는 갱신 보너스를 주지 않고, 기존 기록을 실제로 단축했을 때 최고 기록 보너스를 지급한다. 기록 키는 현재처럼 트랙·난이도·규칙·기체 성능을 포함한다. 새 기체나 강화로 기록 그룹이 생겼다고 갱신 보너스를 주지는 않는다.

완주할 때마다 보상하며, 중도 포기·재시작에는 지급하지 않는다. 집중 모드를 장착한 경기는 사용 여부와 관계없이 기본 보상의 80%만 지급하고 기록 갱신 보너스를 제외한다.

결과에는 `이번 경기 획득 +합계 P`를 크게 표시하고 보유 포인트를 별도로 보여준다. 경쟁 레이스는 최종 순위와 순위 보너스를 바로 표시하며 기본·클린/안전 통과·신기록·첫 통과·순위 보상과 벌점은 펼쳐서 확인한다. 결과 화면을 다시 열거나 새로고침해도 같은 경기 보상을 중복 지급하지 않는다. 초기 목표는 초급 3~5회 완주로 첫 강화, 8~12회로 두 번째 기체를 구매하는 정도다.

코스 이탈은 강제 복귀 없이 전진을 유지하고 감속하며, 1회당 7P 벌점을 기록한다. 안전하게 노면 안쪽으로 돌아온 뒤 다시 이탈할 때만 추가 부과한다. 주행에는 `코스 이탈 · -7P`, 결과에는 횟수·누적 벌점을 표시한다. 벌점 기록·표시와 완주 보상 차감을 구현했다. `max(0, 기본 보상 + 추가 보상 - 벌점)`을 지급하고 보유 잔액을 음수로 만들지 않는다.

클린은 각 랩의 앞·뒤 절반을 따로 판정한다. 앞 절반에서 충돌해도 뒤 절반이 클린이면 +3P를 받는다. 완주한 반 랩만 계산하며 마지막 반 랩도 포함한다. 반 랩·랩 완료 안내에 클린 보너스를 표시한다. 안전 주행보다 기록 단축의 보상이 크도록 설정하며, 기존 저장 보상의 금액은 소급 변경하지 않는다.

## 기체 구매와 강화

기체는 최고 속도뿐 아니라 조향·제동·부스트 지속 시간의 차이로 선택하게 한다. 기체 모델과 발광·불꽃 색 조합도 구분한다.

전달된 `incoming-resources/racing-drone/`의 5종을 사용한다. 기존 기본 기체는 Vanguard로 연결하고 나머지 4종을 구매 대상으로 둔다. 모델과 주색·보조색은 전달 자료를 따른다. 아래 성능은 현재 시험 주행에 적용한 초기값이며 가격은 현재 적용 값이다.

| 기체 | 주색 / 보조색 | 성능 성격 제안 | 현재 가격 |
| --- | --- | --- | ---: |
| Vanguard | 청록 / 주황 | 기존 DR-01의 균형형 성능 | 무료 |
| Needle | 라임 / 마젠타 | 직선 최고 속도 우수, 급커브에서 감속 필요 | 1,200 P |
| Hammerhead | 앰버 / 아이스블루 | 제동과 충돌 후 회복 우수, 가속은 느림 | 1,000 P |
| Catamaran | 바이올렛 / 민트 | 조향 우수, 직선 최고 속도는 낮음 | 900 P |
| Halo | 레드 / 골드 | 가속과 부스트 진입 우수, 배터리 소모가 큼 | 1,400 P |

상점 카탈로그와 미리보기는 5종으로 구성한다. 기체 성능은 비싼 기체가 모든 항목에서 우수해지는 방식보다, 트랙과 조종 취향에 따라 선택하는 방향으로 조정한다. 기체별 모델·색상과 실제 성능은 별도 설정으로 관리한다.

### 구현된 시험 주행 성능

| 기체 | 가속 m/s² | 일반 / 부스트 / 2단계 km/h | 좌우 핸들링 °/s | 벽 충돌 감속 | 제동 m/s² |
| --- | ---: | --- | ---: | ---: | ---: |
| Vanguard | 46 | 306 / 450 / 558 | 93 | 44% | 70 |
| Needle | 42 | 360 / 522 / 630 | 82 | 53% | 66 |
| Hammerhead | 38 | 281 / 414 / 522 | 86 | 28% | 90 |
| Catamaran | 50 | 295 / 432 / 540 | 112 | 48% | 78 |
| Halo | 60 | 324 / 486 / 612 | 88 | 51% | 72 |

핸들링은 216km/h에서 같은 조향 입력으로 비교한 값이다. 속도가 증가하면 실제 조향도 달라진다. 충돌 감속은 벽 기준 속도 손실이며 낮을수록 유리하다. 전기선은 장애물 강도를 곱해 더 크게 감속한다. 충돌 뒤 가속은 정상의 35%에서 서서히 회복하며, 장애물은 1.6초, 기체 접촉은 0.55초, 경계·이탈은 1초가 걸린다. 오르막은 조향이 최대 22% 강해지고 내리막은 최대 22% 약해진다. Halo는 배터리 소모 0.24/s로 부스트 2단계 진입 2.5초, 나머지는 0.20/s로 3초다. 격납고에서는 보유 기체를 선택하며 구매·장착·강화 상태는 재접속 후에도 유지한다.

성능과 표시값은 `src/game/drone/droneCatalog.ts`의 공통 설정을 사용한다. 이후 강화 결과도 같은 표시 함수에 전달한다.

### 기체와 트랙의 색상 연동 제안

기체 장착 시 트랙의 가장자리 네온선·노면 장식선, 주행 잔광을 주색으로 맞춘다. 부스트 빗금·외곽 왜곡에는 보조색을 사용해 평상시와 부스트를 구분한다. 불꽃은 기존처럼 밝은 코어·몸통·꼬리의 다색 조합을 유지한다.

출발 아크·활성 체크포인트·장애물의 통과 가능/불가 표시와 충돌 안내는 역할별 색을 유지한다. 특히 Halo의 빨강과 Hammerhead의 앰버가 위험·전환 안내와 섞이지 않도록 트랙 장식은 밝기를 낮추고, 안내는 위치·굵기·점멸도 함께 사용한다. 기체색별 Bloom 번짐과 노면 대비는 실제 화면에서 비교한다.

상점 기체 미리보기에는 짧은 트랙 구간도 표시해 구매 전 색상 조합을 볼 수 있게 한다. 경기 전환 시 테마를 적용하며 주행 중 재질이나 트랙을 다시 생성하지 않는다. 향후 사용자 선택을 위한 기본 트랙색 옵션과 외형 상품을 연결할 수 있도록 기체 성능·외형 테마·위험 표시를 분리한다. 경쟁 레이스에서는 플레이어 기체의 색이 트랙 테마를 정하고 상대 기체는 각각의 색을 유지한다.

강화는 기체별로 영구 적용하며 각 항목 3단계부터 시작한다. 단계별 비용은 300 / 500 / 800 P 초안이다.

| 강화 | 단계당 효과 초안 | 연결할 성능 |
| --- | --- | --- |
| 추진기 | 일반·부스트 최고 속도 +4%, 가속 +3%, 등판 저항 -4% | topSpeed, boostSpeed, boostStage2Speed, acceleration, slopeSensitivity |
| 브레이크 | 제동력 +12% | braking |
| 자세 제어 | 조향 반응 +5%, 고속 조향 손실 -8%, 선회 저항 -6%, 조향 저항 -8% | maxYawRate, highSpeedSteeringLoss, corneringDrag, steeringDrag |
| 부스트 배터리 | 소모량 -5%, 회복 +4% | boostDrain, boostRecovery |
| 횡방향 안정기 | 좌우 제동력 +25%, 입력 해제·반대 조향의 잔류 미끄러짐 감소 | lateralBraking |

효과는 단계 합계로 계산해 최종 배율 하나를 적용한다. 3단계 추진기의 최고 속도는 +12%다. 브레이크 강화는 최저 전진 속도를 낮추지 않고 목표 속도에 더 빨리 도달하게 한다. 강화된 기체도 고속의 급커브에서 감속이 필요하도록 조정한다.

현재의 DroneConfiguration과 resolveDroneConfiguration에 구매·장착 결과를 연결한다. 경기 도중 구매나 장착 변경은 하지 않는다. 속도 연출과 불꽃 스타일은 실제 성능과 별도 설정을 유지해 이후 외형 아이템을 지원한다.

v0.12.0부터 평지 직선의 기준 속도와 실제 속도를 구분한다. 오르막·코너·조향·고도 이동의 저항이 기체별로 다르며 기존 강화에도 연결한다. 계수와 후속 상품 후보는 [주행 속도 계산](DRIVING_DYNAMICS.md)에 기록한다.

v0.13.0부터 좌우 핸들링과 좌우 제동을 따로 표시한다. 좌우 제동은 잔류 이동 방향이 90% 줄어드는 기준 시간으로, 짧을수록 즉각 멈춘다. 횡방향 안정기는 기체별 3단계까지 강화하며 전진 브레이크·조향 속도를 바꾸지 않는다. 기존 4종 강화 저장에는 안정기 0단계를 추가하며 보유 기체·포인트·강화·캠페인 기록을 유지한다.

## 소모 아이템

아이템은 상점에서 보유 수량을 구매하고, 두 종류의 슬롯에 같은 아이템을 각각 최대 5개씩 장착한다(총 최대 10개). 집중 모드도 한 종류로 센다. 아이템 탭에서 타임어택/경쟁 레이스를 선택한다. 수동 아이템은 슬롯 1 **Q**, 슬롯 2 **E**로 사용하며, 소진되거나 자동 아이템이 있어도 슬롯 위치는 바뀌지 않는다. 게임패드 LB는 현재 사용 가능한 첫 수동 아이템을 사용한다. 모바일 버튼은 아이콘·남은 수량/시간을 표시한다. 패링은 ←/→이며 E 호환 입력은 제거했다.

2026-10-12 사용자 확정 반영:

| 아이템 | 동작 | 사용할 모드 | 현재 가격 |
| --- | --- | --- | ---: |
| 집중 모드 | 실제 시간 5초 동안 모든 기체의 주행 속도를 70% 낮춤(30% 속도), 경기 시계는 정상 | 타임어택·경쟁 레이스 | 60 P |
| 시간 정지 | 실제 시간 3초 동안 주행 중인 상대 AI의 이동을 멈춤 | 경쟁 레이스 | 120 P |
| 전파 교란 | 앞쪽 180m 안의 가까운 AI 최대 2대의 목표 속도를 실제 시간 3초 동안 50%로 낮춤 | 경쟁 레이스 | 100 P |
| 지원 미사일 | 2랩부터 새로운 실제 추월에 자동 발사, 0.4초 비행 후 상대 5초 정지 | 경쟁 레이스 | 100 P |
| 선행 출발 | 출발 때 자동 사용, 상대가 5초 늦게 출발 | 경쟁 레이스 | 100 P |
| 부스트 강화 10% / 20% / 30% | 출발 때 자동 사용, 레이스 내내 부스트 1·2단계 속도 강화 | 타임어택·경쟁 레이스 | 400 / 600 / 800 P |
| 기본 속도 강화 10% / 20% / 30% | 출발 때 자동 사용, 레이스 내내 일반 주행 최고 속도 강화 | 타임어택·경쟁 레이스 | 500 / 800 / 1100 P |

선행 출발·강화 아이템은 장착 수량에 관계없이 경기당 1개만 소비한다. 강화는 각 계열에서 가장 높은 단계만 적용하고 낮은 단계 재고는 보존한다. 기본 속도와 부스트 강화는 함께 적용할 수 있으며 두 비율을 서로 곱하지 않는다. 기체의 영구 강화가 적용된 성능을 기준으로 각각의 속도 한계에 비율을 적용한다. 가속력·조향·배터리 소모량·각성 속도는 그대로다. 자동 발동 전 저장소에 수량을 예약하고 출발 카운트다운에서 동기적으로 효과를 켠다. 취소되거나 발동하지 못한 예약만 환불한다. 선행 출발 대기 중 상대와의 접촉·니어미스는 판정하지 않는다.

시간 정지는 트랙이나 플레이어를 멈추는 효과가 아니다. 고정 장애물 자체가 사라지지도 않는다. 현재는 고정 장애물만 있으므로 AI 이동에 적용한다. 움직이거나 작동 주기가 있는 장애물이 추가되면 정지 효과 연결을 확장한다. 전파 교란의 앞뒤는 랩을 포함한 누적 주행 거리로 판단하며, 대상이 없거나 모두 완주했다면 수량을 소비하지 않는다. 효과를 받은 AI에는 시간 정지의 밝은 청록 링 또는 전파 교란의 주황 링을 표시한다.

경쟁 레이스의 집중 모드는 플레이어와 모든 AI에게 함께 적용한다. 집중 모드 중 공식 경기 시간은 실제 경과 시간대로 흐른다. 시간 정지·전파 교란도 경기 시계를 멈추지 않는다. 어떤 아이템이든 장착하면 실제 사용하지 않아도 보조 경기로 분류하며, 기록은 일반 기록과 따로 저장한다. 기본 완주 보상은 80%이며 기록 보너스는 없다. 시간 정지와 전파 교란은 타임어택에서 구매·장착·사용할 수 없다. 경쟁 레이스 장착 상태는 저장하되 타임어택 출전에는 포함하지 않는다.

수동 아이템은 카운트다운·일시정지·결과에서는 사용할 수 없다. 출발 자동 아이템은 카운트다운에서만 발동한다. 일시정지 중 효과와 재사용 대기시간도 멈춘다. 경기 중 효과가 실제 발동할 때 수량을 한 번 차감한다. 미사용 아이템은 그대로 남고, 사용 후 재시작하거나 포기해도 돌려주지 않는다. 수동 아이템·미사일은 공통으로 발동 후 3초 재사용 대기시간을 둔다. 집중 모드 자체는 5초 대기시간을 두며, 출발 자동 아이템은 이 대기시간을 만들지 않는다. 저장을 먼저 예약하고 실제 발동을 확인하며, 발동하지 못한 예약만 환불한다. 브라우저 강제 종료 시 미확정 예약은 자동 환불하지 않는다.

#### Claude 화면 연결 계약

순수 모듈 `src/game/driving/supportMissile.ts`:

```ts
export const SUPPORT_MISSILE_FLIGHT = 0.4;
export const SUPPORT_MISSILE_STOP = 5;
export type MissilePosition = { x: number; y: number; z: number };
export interface SupportMissileSnapshot {
  phase: 'armed' | 'waiting' | 'flying' | 'hit' | 'spent';
  requestId: number | null;
  canLaunch: boolean;
  targetId: string | null;
  progress: number; // 0~1, real seconds / 0.4; armed/waiting = 0
  position: MissilePosition | null; // Three.js와 같은 월드 좌표
  launchPosition: MissilePosition | null;
  hitEventId: number; // 경기 내 단조 증가, 새 경기에서 초기화
  stopRemaining: number; // 5.0→0, 일시정지 중 불변
}
```

`RaceSnapshot.supportMissile`와 `RaceSnapshot.timeAttack.supportMissile`은 같은 `SupportMissileSnapshot | null`이다. 미장착은 null. `armed`=자동 대기, `waiting`=유효 추월 후 예약/대기시간 대기, `flying`=비행, `hit`=대상 정지 중, `spent`=소모 완료(명중 취소 포함). `position`은 비행 중 미사일 위치이며 명중 후 마지막 명중 위치를 유지한다. `hitEventId`를 이전 프레임과 비교해 한 번만 연출한다. HUD가 저빈도로 갱신돼도 놓치지 않도록 종료 후에도 유지한다. 비행 취소는 position=null, hitEventId 증가 없음. 대상 ID는 `competition.standings[].id` / 세션 rivals[].id와 일치하고 정지 중 순위표 `effect`는 `'support-missile'`.

`createRaceSession()`과 `Race`의 공개 메서드:

```ts
launchSupportMissile(requestId: number): boolean;
rejectSupportMissile(requestId: number): void;
```

이 메서드는 자동 예약 브리지 전용이다. `raceApp.ts`가 snapshot의 canLaunch/requestId를 감시해 `reserveSupportMissile(...)`로 저장 예약→재검증→발사→확정/반환까지 연결했다. Claude가 발사 호출이나 구매·소비를 추가할 필요 없다. `useRivalItem('support-missile')`은 항상 false. `createRace.ts`에는 타입·snapshot·메서드 전달만 추가했다. 매 프레임 이펙트 갱신은 기존 `timeAttack.snapshot().supportMissile`을 읽으면 된다. 상점/출전 장비는 공통 카탈로그에서 표시하며 아이콘·연출은 Claude가 담당한다.
