# 상점과 포인트 기획

작성: 2026-10-04 · 갱신: 2026-10-05
상태: P6-A~C 구현. 포인트 지급, 기체 구매·장착, 영구 강화, 집중 모드를 연결했다. 가격·보상·조종 밸런스는 플레이 테스트 후 조정한다. AI 상대 아이템은 P5 이후 범위다.

## 경기와 성장의 흐름

타임어택 또는 AI 레이스 3랩 완주 → 결과 화면에서 포인트 획득 → 격납고의 상점에서 구매 → 기체·강화·아이템을 장착 → 다음 경기 시작.

v0.6.0에서는 타임어택과 AI 레이스에 같은 완주 보상을 지급하고 최고 기록은 경기 방식별로 분리한다. 순위별 추가 보상과 상대 기체에 쓰는 아이템은 후속 범위다. 최초 기체는 무료이며 구매 없이 모든 난이도를 플레이할 수 있다.

## 포인트 보상

| 조건 | 지급 초안 |
| --- | ---: |
| 초급 타임어택 완주 | 100 P |
| 중급 타임어택 완주 | 150 P |
| 고급 타임어택 완주 | 220 P |
| 충돌·이탈·복귀 없이 완주 | +20 P |
| 기존 개인 최고 기록 갱신 | +20 P |

첫 기록에는 갱신 보너스를 주지 않고, 기존 기록을 실제로 단축했을 때 최고 기록 보너스를 지급한다. 기록 키는 현재처럼 트랙·난이도·규칙·기체 성능을 포함한다. 새 기체나 강화로 기록 그룹이 생겼다고 갱신 보너스를 주지는 않는다.

완주할 때마다 보상하며, 중도 포기·재시작에는 지급하지 않는다. 복귀를 사용해도 정상 순서로 완주하면 기본 보상을 받는다. 집중 모드를 장착한 경기는 사용 여부와 관계없이 기본 보상의 80%만 지급하고 기록 갱신 보너스를 제외한다.

결과에 기본 보상·추가 보상·획득 합계·보유 포인트를 표시한다. 결과 화면을 다시 열거나 새로고침해도 같은 경기 보상을 중복 지급하지 않는다. 초기 목표는 초급 3~5회 완주로 첫 강화, 8~12회로 두 번째 기체를 구매하는 정도다.

코스 이탈은 강제 복귀 없이 전진을 유지하고 감속하며, 1회당 5P 벌점을 기록한다. 안전하게 노면 안쪽으로 돌아온 뒤 다시 이탈할 때만 추가 부과한다. 주행에는 `코스 이탈 · -5P`, 결과에는 횟수·누적 벌점을 표시한다. 벌점 기록·표시와 완주 보상 차감을 구현했다. `max(0, 기본 보상 + 추가 보상 - 벌점)`을 지급하고 보유 잔액을 음수로 만들지 않는다.

## 기체 구매와 강화

기체는 최고 속도뿐 아니라 조향·제동·부스트 지속 시간의 차이로 선택하게 한다. 기체 모델과 발광·불꽃 색 조합도 구분한다.

전달된 `incoming-resources/racing-drone/`의 5종을 사용한다. 기존 기본 기체는 Vanguard로 연결하고 나머지 4종을 구매 대상으로 둔다. 모델과 주색·보조색은 전달 자료를 따른다. 아래 성능은 현재 시험 주행에 적용한 초기값이며 가격은 현재 적용 값이다.

| 기체 | 주색 / 보조색 | 성능 성격 제안 | 현재 가격 |
| --- | --- | --- | ---: |
| Vanguard | 청록 / 주황 | 기존 DR-01의 균형형 성능 | 무료 |
| Needle | 라임 / 마젠타 | 직선 최고 속도 우수, 급커브에서 감속 필요 | 1,200 P |
| Hammerhead | 앰버 / 아이스블루 | 제동과 충돌 후 회복 우수, 가속은 느림 | 1,000 P |
| Catamaran | 바이올렛 / 민트 | 조향 우수, 직선 최고 속도는 낮음 | 900 P |
| Halo | 레드 / 골드 | 가속과 부스트 진입 우수, 배터리 소모가 큼 | 1,400 P |

상점 카탈로그와 미리보기는 5종으로 구성한다. 기체 성능은 비싼 기체가 모든 항목에서 우수해지는 방식보다, 트랙과 조종 취향에 따라 선택하는 방향으로 조정한다. 기체별 모델·색상과 실제 성능은 별도 설정으로 관리한다.

### 구현된 시험 주행 성능

| 기체 | 가속 m/s² | 일반 / 부스트 / 2단계 km/h | 좌우 핸들링 °/s | 벽 충돌 감속 | 제동 m/s² |
| --- | ---: | --- | ---: | ---: | ---: |
| Vanguard | 46 | 306 / 450 / 558 | 93 | 38% | 70 |
| Needle | 42 | 360 / 522 / 630 | 82 | 46% | 66 |
| Hammerhead | 38 | 281 / 414 / 522 | 86 | 24% | 90 |
| Catamaran | 50 | 295 / 432 / 540 | 112 | 42% | 78 |
| Halo | 60 | 324 / 486 / 612 | 88 | 44% | 72 |

핸들링은 216km/h에서 같은 조향 입력으로 비교한 값이다. 속도가 증가하면 실제 조향도 달라진다. 충돌 감속은 벽 기준 속도 손실이며 낮을수록 유리하다. 전기선은 장애물 강도를 곱해 더 크게 감속한다. Halo는 배터리 소모 0.24/s로 부스트 2단계 진입 2.5초, 나머지는 0.20/s로 3초다. 격납고에서는 보유 기체를 선택하며 구매·장착·강화 상태는 재접속 후에도 유지한다.

성능과 표시값은 `src/game/drone/droneCatalog.ts`의 공통 설정을 사용한다. 이후 강화 결과도 같은 표시 함수에 전달한다.

### 기체와 트랙의 색상 연동 제안

기체 장착 시 트랙의 가장자리 네온선·노면 장식선, 주행 잔광을 주색으로 맞춘다. 부스트 빗금·외곽 왜곡에는 보조색을 사용해 평상시와 부스트를 구분한다. 불꽃은 기존처럼 밝은 코어·몸통·꼬리의 다색 조합을 유지한다.

출발 아크·활성 체크포인트·장애물의 통과 가능/불가 표시와 충돌 안내는 역할별 색을 유지한다. 특히 Halo의 빨강과 Hammerhead의 앰버가 위험·전환 안내와 섞이지 않도록 트랙 장식은 밝기를 낮추고, 안내는 위치·굵기·점멸도 함께 사용한다. 기체색별 Bloom 번짐과 노면 대비는 실제 화면에서 비교한다.

상점 기체 미리보기에는 짧은 트랙 구간도 표시해 구매 전 색상 조합을 볼 수 있게 한다. 경기 전환 시 테마를 적용하며 주행 중 재질이나 트랙을 다시 생성하지 않는다. 향후 사용자 선택을 위한 기본 트랙색 옵션과 외형 상품을 연결할 수 있도록 기체 성능·외형 테마·위험 표시를 분리한다. AI 레이스에서는 플레이어 기체의 색이 트랙 테마를 정하고 상대 기체는 각각의 색을 유지한다.

강화는 기체별로 영구 적용하며 각 항목 3단계부터 시작한다. 단계별 비용은 300 / 500 / 800 P 초안이다.

| 강화 | 단계당 효과 초안 | 연결할 성능 |
| --- | --- | --- |
| 추진기 | 일반·부스트 최고 속도 +4%, 가속 +3% | topSpeed, boostSpeed, boostStage2Speed, acceleration |
| 브레이크 | 제동력 +12% | braking |
| 자세 제어 | 조향 반응 +5%, 고속 조향 손실 감소 | maxYawRate, highSpeedSteeringLoss |
| 부스트 배터리 | 소모량 -5%, 회복 +4% | boostDrain, boostRecovery |

효과는 단계 합계로 계산해 최종 배율 하나를 적용한다. 3단계 추진기의 최고 속도는 +12%다. 브레이크 강화는 최저 전진 속도를 낮추지 않고 목표 속도에 더 빨리 도달하게 한다. 강화된 기체도 고속의 급커브에서 감속이 필요하도록 조정한다.

현재의 DroneConfiguration과 resolveDroneConfiguration에 구매·장착 결과를 연결한다. 경기 도중 구매나 장착 변경은 하지 않는다. 속도 연출과 불꽃 스타일은 실제 성능과 별도 설정을 유지해 이후 외형 아이템을 지원한다.

## 소모 아이템

아이템은 상점에서 보유 수량을 구매하고 다음 경기용으로 합계 최대 2개를 장착한다. 아이템 탭에서 타임어택/AI 레이스를 선택한다. 주행에서는 기존 고도·부스트 조작 영역 위쪽에 전용 버튼을 표시하며, 기체 뷰를 PIP로 옮기면 버튼도 따라간다. V 또는 게임패드 LB는 집중 모드, 시간 정지, 전파 교란 순서로 현재 사용 가능한 첫 아이템을 사용한다.

| 아이템 | 동작 | 사용할 모드 | 현재 가격 |
| --- | --- | --- | ---: |
| 집중 모드 | 실제 시간 2초 동안 전체 주행 시뮬레이션을 45% 속도로 진행 | 보조 타임어택·AI 레이스 | 60 P |
| 시간 정지 | 실제 시간 1초 동안 주행 중인 상대 AI의 이동을 멈춤. 플레이어는 계속 전진 | AI 레이스 | 120 P |
| 전파 교란 | 앞쪽 180m 안의 가까운 AI 최대 2대의 목표 속도를 실제 시간 3초 동안 50%로 낮춤 | AI 레이스 | 100 P |

시간 정지는 트랙이나 플레이어를 멈추는 효과가 아니다. 고정 장애물 자체가 사라지지도 않는다. 현재는 고정 장애물만 있으므로 AI 이동에 적용한다. 움직이거나 작동 주기가 있는 장애물이 추가되면 정지 효과 연결을 확장한다. 전파 교란의 앞뒤는 랩을 포함한 누적 주행 거리로 판단하며, 대상이 없거나 모두 완주했다면 수량을 소비하지 않는다. 효과를 받은 AI에는 시간 정지의 밝은 청록 링 또는 전파 교란의 주황 링을 표시한다.

AI 레이스의 집중 모드는 플레이어와 모든 AI에게 함께 적용한다. 집중 모드 중 공식 경기 시간은 실제 경과 시간대로 흐른다. 시간 정지·전파 교란도 경기 시계를 멈추지 않는다. 어떤 아이템이든 장착하면 실제 사용하지 않아도 보조 경기로 분류하며, 기록은 일반 기록과 따로 저장한다. 기본 완주 보상은 80%이며 기록 보너스는 없다. 시간 정지와 전파 교란은 타임어택에서 구매·장착·사용할 수 없다. AI 레이스 장착 상태는 저장하되 타임어택 출전에는 포함하지 않는다.

카운트다운·일시정지·결과에서는 사용할 수 없다. 일시정지 중 효과와 재사용 대기시간도 멈춘다. 경기 중 효과가 실제 발동할 때 수량을 한 번 차감한다. 미사용 아이템은 그대로 남고, 사용 후 재시작하거나 포기해도 돌려주지 않는다. 모든 아이템은 공통으로 발동 후 3초 재사용 대기시간을 둔다. 저장을 먼저 예약하고 실제 발동을 확인하며, 발동하지 못한 예약만 환불한다. 브라우저 강제 종료 시 미확정 예약은 자동 환불하지 않는다.

## 화면 배치

- 격납고·상점: 동일한 헤더에 메뉴 이동, 음향, 앱 설치·버전, 보유 포인트를 배치한다. 격납고에서는 보유 기체를 큰 사각형 버튼으로 선택한다. 셀렉트박스·중복 이름·하단 보기 도구 줄은 제거했다. 기체 미리보기의 휠 확대·축소를 끄고 페이지 스크롤을 허용한다.
- 상점: 기체 / 강화 / 아이템 탭. 보유·장착·구매 가능 여부와 가격을 구분한다.
- 기체·강화 상세: 현재와 구매 후 최고 속도·제동·조향·부스트를 비교한다. 고속형의 조종 부담도 짧게 안내한다.
- 경기 준비: 장착 기체·아이템 슬롯과 일반/보조 타임어택 구분을 표시한다.
- 결과: 보상 계산과 상점 이동 버튼을 제공한다. 주행 중 포인트·가격 정보는 표시하지 않는다.

보유 기체는 상점에서 장착하거나 구매가의 80%로 판매한다. 반환 포인트를 표시하고 판매를 확정해야 저장한다. 기본 기체 Vanguard는 판매할 수 없다. 강화 비용은 반환하지 않으며 판매 시 해당 강화도 삭제한다. 장착 중인 기체를 판매하면 Vanguard로 자동 전환한다. 재구매하면 강화는 0단계로 시작한다. 판매와 반환은 하나의 저장 트랜잭션으로 처리해 중복 환불을 막는다.

구매와 장착은 구분한다. 구매 후 바로 장착할 수 있으며, 이미 소유한 기체를 다시 구매하지 않는다. 잔액이 모자라면 부족한 포인트를 버튼 옆에 표시한다.

## 저장과 게임 규칙

처음에는 이 브라우저의 로컬 진행 저장으로 시작한다. 기존 최고 기록 저장과는 별도의 버전 있는 IndexedDB 진행 데이터를 사용한다. BroadcastChannel로 다른 탭에 변경을 알린다. 계정·기기 간 동기화는 후속 범위다.

- 진행 데이터: 스키마 버전, 포인트 잔액, 소유 기체, 기체별 강화 단계, 아이템 수량, 장착 상태, 이미 보상한 경기 ID.
- 보상: 경기 시작 시 생성한 ID를 완주 결과에 보관한다. 잔액 증가와 보상 ID 등록을 하나의 진행 데이터 쓰기로 반영한다.
- 구매: 잔액 차감과 소유권·강화·수량 증가를 한 번에 저장한다. 저장 실패 시 성공으로 표시하지 않고 기존 상태를 유지한다.
- 여러 탭: 쓰기 작업을 직렬화하고 저장된 최신 진행 데이터를 읽어 검증한다. 동시에 구매하거나 보상받아 잔액이 덮어써지는 일을 막는다.
- 불러오기: 음수·소수 잔액, 알 수 없는 상품, 강화 한도 초과, 잘못된 수량을 검증한다. 저장 문제로 주행과 기존 기록 조회를 막지 않는다.
- 경기 설정: 출발 시 확정한 기체·강화 성능을 기록 키에 넣는다. 보조 아이템 사용 여부도 기록 그룹을 나누는 조건이다.

포인트 지급·구매·장착을 렌더링 코드에서 분리한다. 보상 계산, 상품 목록, 진행 저장, 구매 처리, 경기용 설정 생성 순서로 작은 모듈을 두고 기존 주행 모델에는 확정된 설정만 전달한다.

## 개발 순서와 진행 관리

완료 체크는 [DEVELOPMENT_CHECKLIST.md](DEVELOPMENT_CHECKLIST.md)의 단일 목록에서 관리한다. 개발 순서는 P4 → P6-A 포인트 → P6-B 상점·기체·강화 → P6-C 집중 모드 → P5 AI 레이스 → P6-D 상대 아이템이다. 이 문서는 보상·구매·저장 규칙과 수치의 근거를 유지한다.

## 로컬 구매 테스트

개발 서버에서는 첫 접속 때 테스트용 1,000,000 P를 한 번 지급한다. 기존 기체·강화·아이템은 유지하고 같은 저장소에 다시 접속해도 추가 지급하지 않는다. 개발 전용 동적 모듈은 배포 빌드에서 제외한다. 브라우저별·주소별 저장소가 달라 `localhost`와 `127.0.0.1`의 진행 상태는 공유되지 않는다.
