# 상점과 포인트 기획

작성: 2026-10-04  
상태: 기획 초안. 포인트 지급·상점·아이템 사용은 아직 구현하지 않았다. 수치와 가격은 플레이 테스트 후 조정한다.

## 경기와 성장의 흐름

타임어택 3랩 완주 → 결과 화면에서 포인트 획득 → 격납고의 상점에서 구매 → 기체·강화·아이템을 장착 → 다음 경기 시작.

현재 타임어택에 먼저 보상을 연결한다. AI 레이스가 추가되면 순위 보상과 상대 기체에 쓰는 아이템을 확장한다. 최초 기체는 무료이며 구매 없이 모든 난이도를 플레이할 수 있다.

## 포인트 보상

| 조건 | 지급 초안 |
| --- | ---: |
| 초급 타임어택 완주 | 100 P |
| 중급 타임어택 완주 | 150 P |
| 고급 타임어택 완주 | 220 P |
| 충돌·복귀 없이 완주 | +20 P |
| 기존 개인 최고 기록 갱신 | +20 P |

첫 기록은 완주 보상만 받고, 기존 기록을 실제로 단축했을 때 최고 기록 보너스를 지급한다. 기록 키는 현재처럼 트랙·난이도·규칙·기체 성능을 포함한다. 새 기체나 강화로 기록 그룹이 생겼다고 갱신 보너스를 주지는 않는다.

완주할 때마다 보상하며, 중도 포기·재시작에는 지급하지 않는다. 복귀를 사용해도 정상 순서로 완주하면 기본 보상을 받는다. 보조 아이템을 사용한 타임어택은 기본 보상의 80%만 지급하고 기록 갱신 보너스를 제외한다.

결과에 기본 보상·추가 보상·획득 합계·보유 포인트를 표시한다. 결과 화면을 다시 열거나 새로고침해도 같은 경기 보상을 중복 지급하지 않는다. 초기 목표는 초급 3~5회 완주로 첫 강화, 8~12회로 두 번째 기체를 구매하는 정도다.

## 기체 구매와 강화

기체는 최고 속도뿐 아니라 조향·제동·부스트 지속 시간의 차이로 선택하게 한다. 기체 모델과 발광·불꽃 색 조합도 구분한다.

| 기체 유형 | 성격 | 가격 초안 |
| --- | --- | ---: |
| 기본 균형형 | 현재 DR-01. 속도·조향·제동 균형 | 무료 |
| 민첩형 | 조향·제동 우수, 직선 속도는 낮음 | 900 P |
| 고속형 | 직선·부스트 속도 우수, 코너에서 감속 필요 | 1,200 P |

최초 구현은 기본 기체와 새 기체 1종으로 시작한다. 기체 3종과 모델·사운드 차이는 후속 확장이다.

강화는 기체별로 영구 적용하며 각 항목 3단계부터 시작한다. 단계별 비용은 300 / 500 / 800 P 초안이다.

| 강화 | 단계당 효과 초안 | 연결할 성능 |
| --- | --- | --- |
| 추진기 | 일반·부스트 최고 속도 +4%, 가속 +3% | topSpeed, boostSpeed, boostStage2Speed, acceleration |
| 브레이크 | 제동력 +12% | braking |
| 자세 제어 | 조향 반응 +5%, 고속 조향 손실 감소 | maxYawRate, highSpeedSteeringLoss |
| 부스트 배터리 | 소모량 -5%, 회복 +4% | boostDrain, boostRecovery |

효과는 단계 합계로 계산해 최종 배율 하나를 적용한다. 3단계 추진기의 최고 속도는 +12%다. 브레이크 강화는 최저 전진 속도를 낮추지 않고 목표 속도에 더 빨리 도달하게 한다. 강화된 기체도 고속의 급커브에서 감속이 필요하도록 조정한다.

현재의 DroneConfiguration과 resolveDroneConfiguration에 구매·장착 결과를 연결한다. 경기 도중 구매나 장착 변경은 하지 않는다. 속도 연출과 불꽃 스타일은 실제 성능과 별도 설정을 유지해 이후 외형 아이템을 지원한다.

## 소모 아이템

아이템은 보유 수량을 구매하고 경기 준비에서 최대 2개를 장착한다. 모바일에도 누르기 쉬운 전용 버튼을 마련하되, 기존 고도·부스트 조작 영역과 겹치지 않도록 별도로 검토한다.

| 아이템 | 동작 초안 | 사용할 모드 | 가격 초안 |
| --- | --- | --- | ---: |
| 집중 모드 | 실제 시간 2초 동안 전체 주행 시뮬레이션을 45% 속도로 진행 | 보조 타임어택·AI 레이스 | 60 P |
| 시간 정지 | 1초 동안 상대 AI의 전진과 동적 장애물의 작동을 멈춤. 플레이어는 계속 전진 | AI 레이스 추가 후 | 120 P |
| 전파 교란 | 가까운 앞쪽 AI 최대 2대의 목표 속도를 3초 동안 50%로 낮춤 | AI 레이스 추가 후 | 100 P |

시간 정지는 트랙이나 플레이어를 멈추는 효과가 아니다. 고정 장애물 자체가 사라지지도 않는다. 현재 전기선처럼 고정된 위험 판정과 달리, 움직이거나 작동 주기가 있는 장애물이 생기면 그 주기를 정지한다.

집중 모드 중 공식 경기 시간은 실제 경과 시간대로 흐른다. 시간 정지·전파 교란도 경기 시계를 멈추지 않는다. 아이템 사용으로 공식 기록의 조건이 달라지는 문제를 피하기 위해 보조 타임어택 기록은 일반 기록과 따로 저장한다. 시간 정지와 전파 교란은 타임어택에서 장착할 수 없다.

카운트다운·일시정지·결과에서는 사용할 수 없다. 경기 중 효과가 실제 발동할 때 수량을 한 번 차감한다. 미사용 아이템은 그대로 남고, 사용 후 재시작하거나 포기해도 돌려주지 않는다. 같은 효과의 중첩은 막고 아이템 발동 간 짧은 공통 재사용 대기시간을 둔다. AI 상대 아이템은 AI 레이스 구현 전에는 판매하지 않는다.

## 화면 배치

- 격납고: 보유 포인트와 상점 진입 버튼을 표시한다.
- 상점: 기체 / 강화 / 아이템 탭. 보유·장착·구매 가능 여부와 가격을 구분한다.
- 기체·강화 상세: 현재와 구매 후 최고 속도·제동·조향·부스트를 비교한다. 고속형의 조종 부담도 짧게 안내한다.
- 경기 준비: 장착 기체·아이템 슬롯과 일반/보조 타임어택 구분을 표시한다.
- 결과: 보상 계산과 상점 이동 버튼을 제공한다. 주행 중 포인트·가격 정보는 표시하지 않는다.

구매와 장착은 구분한다. 구매 후 바로 장착할 수 있으며, 이미 소유한 기체를 다시 구매하지 않는다. 잔액이 모자라면 부족한 포인트를 버튼 옆에 표시한다.

## 저장과 게임 규칙

처음에는 이 브라우저의 로컬 진행 저장으로 시작한다. 기존 최고 기록 저장과는 별도의 버전 있는 진행 데이터를 사용한다. 계정·기기 간 동기화는 후속 범위다.

- 진행 데이터: 스키마 버전, 포인트 잔액, 소유 기체, 기체별 강화 단계, 아이템 수량, 장착 상태, 이미 보상한 경기 ID.
- 보상: 경기 시작 시 생성한 ID를 완주 결과에 보관한다. 잔액 증가와 보상 ID 등록을 하나의 진행 데이터 쓰기로 반영한다.
- 구매: 잔액 차감과 소유권·강화·수량 증가를 한 번에 저장한다. 저장 실패 시 성공으로 표시하지 않고 기존 상태를 유지한다.
- 여러 탭: 쓰기 작업을 직렬화하고 저장된 최신 진행 데이터를 읽어 검증한다. 동시에 구매하거나 보상받아 잔액이 덮어써지는 일을 막는다.
- 불러오기: 음수·소수 잔액, 알 수 없는 상품, 강화 한도 초과, 잘못된 수량을 검증한다. 저장 문제로 주행과 기존 기록 조회를 막지 않는다.
- 경기 설정: 출발 시 확정한 기체·강화 성능을 기록 키에 넣는다. 보조 아이템 사용 여부도 기록 그룹을 나누는 조건이다.

포인트 지급·구매·장착을 렌더링 코드에서 분리한다. 보상 계산, 상품 목록, 진행 저장, 구매 처리, 경기용 설정 생성 순서로 작은 모듈을 두고 기존 주행 모델에는 확정된 설정만 전달한다.

## 구현 체크리스트

P6의 포인트·상점 부분은 P5 AI 레이스보다 먼저 진행할 수 있다.

- [ ] P6-A: 보상 규칙·진행 데이터·완주 포인트·결과 화면 잔액.
- [ ] P6-A: 중복 보상, 포기·재시작, 저장 실패, 여러 탭 동시 처리 검증.
- [ ] P6-B: 상점 UI, 새 기체 1종, 속도·브레이크 강화, 구매·장착·저장.
- [ ] P6-B: 강화 성능이 다음 경기에 반영되고 기록 그룹이 분리되는지 검증.
- [ ] P6-B 후속: 자세 제어·배터리 강화, 세 번째 기체, 외형 상품.
- [ ] P6-C: 집중 모드, 아이템 수량·슬롯·발동, 보조 기록·보상 구분.
- [ ] P5 이후 P6-D: 시간 정지·전파 교란, AI 반응·효과 표시.
- [ ] 모바일 세로·가로 화면에서 구매와 장착, 경기 중 아이템 조작 검증.
- [ ] 실제 완주 시간과 첫 구매까지 필요한 경기 수를 보고 보상·가격 조정.
